Question 2

  1. Find the left-hand and right-hand limits at $x=3$.
  2. Determine whether any value of $k$ can make $f$ continuous at $3$.
  3. Justify the conclusion.

Question 3

Classify each discontinuity.

  1. The graph approaches the same finite value from both sides, but the point is missing.
  2. The left- and right-hand limits are finite but unequal.
  3. The function grows without bound as $x$ approaches the point.

Station 1 Answers

Question 1

The graph approaches $3$, while the filled point gives $f(-2)=-1$. The function is not continuous because the limit does not equal the function value.

Question 2

The left-hand limit is $7$ and the right-hand limit is also $7$, so choosing $k=7$ makes $f(3)=7$ and the function continuous.
Rationale: Compare the function value with the left-hand and right-hand limiting behavior. Continuity requires the two-sided limit to exist and equal the function value.

Question 3

(a) Removable discontinuity. (b) Jump discontinuity. (c) Infinite discontinuity.
Rationale: Trace the graph toward the target x-value separately from the left and from the right. A two-sided limit exists only when those approached y-values agree.
