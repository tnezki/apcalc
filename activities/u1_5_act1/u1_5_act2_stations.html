  1. Find $\lim_{x\to\infty}f(x)$.

Question 3

A continuous function on $[1,5]$ satisfies $f(1)=-4$ and $f(5)=6$.

  1. Use the Intermediate Value Theorem to decide whether some $c$ must satisfy $f(c)=2$.
  2. Decide whether IVT guarantees a point where $f(c)=9$.
  3. State the hypothesis and between-values condition used.

Station 1 Answers

Question 1

The vertical asymptote is $x=2$ and the horizontal asymptote is $y=-1$. For example, $\lim_{x\to2^+}f(x)=+\infty$ and $\lim_{x\to\infty}f(x)=-1$.

Question 2

Both limits equal $3$, so the horizontal asymptote is $y=3$. The fraction tends to $0$ in both directions.
Rationale: Compare the dominant terms as x grows without bound. Their ratio determines the finite end-behavior limit and any horizontal asymptote.

Question 3

IVT guarantees a value of $2$ because $2$ lies between $-4$ and $6$ and the function is continuous. It does not guarantee $9$ because $9$ is outside that range.

Question 6

The left-hand limit is $7$ and the right-hand limit is $7$, so $k=7$ makes the function continuous.
