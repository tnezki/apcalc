Time
18–20 minutes
Format
Machine exploration + sort + design
Name
________________
Learning Target: Students will interpret functions as rules that connect inputs and outputs without relying on formal domain and range language.
Directions
  • Work with a partner or group of 3.
  • Predict before calculating.
  • Test more than one input before deciding how a rule works.
  • A relationship works like a function only when each input has exactly one output.
