The Function Machine Mystery

Sort + design · designed for 18–20 minutes

Time18–20 minutes
Groups2–3 students
Core ideaInputs, Outputs, and Functions

Why This Investigation Fits Section 1.2

The current notes introduce function notation and the idea that each input must have exactly one output, while intentionally avoiding formal domain/range language. The investigation builds that definition from examples and nonexamples.

Materials Per Group

  • Student investigation
  • Pencil
  • Optional scissors for relationship cards

Answer / Evidence Guide

Machines: Add 3 gives 4, 7, 13 for inputs 1,4,10. Multiply by 2 gives 2,8,20. Square gives 1,16,100.

Rewards program: input = levels, output = total points; 10 is starting amount and 2 is repeated change.

Watch for: the overgeneralization “numbers cannot repeat.” Ask whether the repeated value is an input or an output.

Strong Synthesis

A function assigns exactly one output to each input. Different inputs can share the same output.
