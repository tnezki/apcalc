Core ideaFunction Families

Why This Investigation Fits Section 1.3

The current course names four families here: linear, quadratic, exponential, and absolute value. The legacy investigation used a constant family; this version deliberately replaces that legacy mismatch with absolute value so the evidence matches the current notes and assessment plan.

Materials Per Group

  • Student investigation
  • Pencil
  • Optional scissors for card sorting

Answer / Evidence Guide

FamilyCardsKey evidence
Linear01, 02, 03, 04Constant difference; straight graph; $x$ to first power.
Absolute Value05, 06, 07, 08V-shape; symmetry; outputs are distances from 0.
Exponential09, 10, 11, 12Constant factor; variable is in exponent; doubling context.
Quadratic13, 14, 15, 16U-shape; $x^2$; square-area context; changing first differences.

Table round: C is exponential; A, B, D have constant differences.

Equation round: B is quadratic; A, C, D are linear.

Watch for: classifying only by graph appearance or confusing quadratic and absolute value because both can be symmetric.

Strong Synthesis

Students should use at least two representations or features to justify a family choice rather than naming from a single clue.
