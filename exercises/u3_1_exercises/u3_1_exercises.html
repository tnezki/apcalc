Foundation

Foundation

Practice
4.For $f(x)=1/x$, write a difference-quotient limit for $f'(2)$ and evaluate it.
Practice
5.A smooth graph is increasing on $(-\infty,-1)$, has a horizontal tangent at $x=-1$, and is decreasing on $(-1,3)$. State the sign of $f'$ on each interval and the value of $f'(-1)$.
Practice
6.Sketch a possible graph of a function whose derivative is always negative.
Practice

AP / Interpretation

AP / Interpretation

AP / Interpretation
