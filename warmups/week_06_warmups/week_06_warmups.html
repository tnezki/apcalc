No CalculatorStrengthen · Derivative definition
Let $f(x)=x^2+1$. What is $f'(3)$?
  1. $3$
  2. $5$
  3. $6$
  4. $9$
  5. $10$
Reveal answers
1A: C. Using the difference quotient, $\frac{(3+h)^2+1-10}{h}=6+h$, so the limit is $6$.
Calculator PermittedRetain · Rates & tangents
For $g(t)=t^3-2t+\sin t$, use a symmetric difference quotient with $h=0.001$ to estimate the instantaneous rate of change at $t=1$.
  1. $0.540$
  2. $1.000$
  3. $1.540$
  4. $2.540$
  5. $3.540$
Reveal answers
1B: C. $\frac{g(1.001)-g(0.999)}{0.002}\approx1.540$.

Calculator PermittedStrengthen · Numerical derivative
A population is modeled by $P(t)=\frac{1200}{1+4e^{-0.3t}}$. Use a symmetric difference quotient with $h=0.01$ to estimate $P'(5)$.
  1. $42.6$
  2. $63.4$
  3. $89.7$
  4. $120.0$
  5. $634.1$
Reveal answers
2A: C. $\frac{P(5.01)-P(4.99)}{0.02}\approx89.7$.
No CalculatorRetain · Continuity
For what value of $k$ is the function continuous at $x=2$? $$f(x)=\begin{cases}\dfrac{x^2-4}{x-2},&x\ne2\\k,&x=2\end{cases}$$
  1. $0$
  2. $2$
  3. $4$
  4. $6$
  5. The function cannot be made continuous.
Reveal answers
2B: C. For $x\ne2$, $f(x)=x+2$, so $\lim_{x\to2}f(x)=4$.

10/8 · 3.2
No CalculatorStrengthen · Differentiability
Which function is continuous at $x=0$ but not differentiable at $x=0$?
  1. $f(x)=x^2$
  2. $f(x)=|x|$
  3. $f(x)=x^3$
  4. $f(x)=x^4$
  5. $f(x)=2x+1$
Reveal answers
3A: B. $|x|$ is continuous at $0$ but has a corner there, so the one-sided derivatives are not equal.
Calculator PermittedRetain · Limit at infinity
The temperature of an object is modeled by $T(t)=72+38e^{-0.12t}$ for $t\ge0$. Which value best describes $\lim_{t\to\infty}T(t)$?
  1. $0$
  2. $38$
  3. $72$
  4. $110$
  5. The limit does not exist.
Reveal answers
3B: C. As $t\to\infty$, $e^{-0.12t}\to0$, so $T(t)\to72$.

10/9 · 3.2
Calculator PermittedStrengthen · Corners from a graph
Let $f(x)=|x^3-2x-1|$. A graphing calculator shows that $x^3-2x-1=0$ at approximately $x=-1.000$, $x=-0.618$, and $x=1.618$. At which of these values does $f$ fail to be differentiable?
  1. $-1.000$ only
  2. $-0.618$ only
  3. $1.618$ only
  4. $-1.000$ and $1.618$ only
  5. All three values
Reveal answers
4A: E. Each is a simple zero of the inside function, so the absolute value creates a corner at each crossing.
No CalculatorRetain · Meaning of derivative
If $f'(c)=0$, which statement must be true?
  1. $f(c)=0$
  2. $f$ has a local maximum at $c$
  3. $f$ has a local minimum at $c$
  4. The tangent line to $y=f(x)$ at $x=c$ is horizontal
  5. $f''(c)=0$
Reveal answers
4B: D. The derivative is the tangent slope, so slope $0$ means a horizontal tangent. It does not by itself guarantee an extremum.

No CalculatorStrengthen · Differentiability theorem
Suppose $f$ is differentiable at $x=4$. Which statement must be true?
  1. $f(4)=0$
  2. $f'(4)=0$
  3. $f$ is continuous at $x=4$
  4. $f$ has a local extremum at $x=4$
  5. $f''(4)$ exists
Reveal answers
5A: C. Differentiability at a point implies continuity at that point.
Calculator PermittedRetain · Numerical limit
Use a calculator to evaluate $q(x)=\frac{\sin(x-2)}{x-2}$ at values close to $x=2$. Which is the best estimate of $\lim_{x\to2}q(x)$?
  1. $-1$
  2. $0$
  3. $0.5$
  4. $1$
  5. The limit does not exist.
Reveal answers
5B: D. Values from both sides approach $1$.
