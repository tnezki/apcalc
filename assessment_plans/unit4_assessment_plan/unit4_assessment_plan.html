AP Calculus AB — Unit 4: Derivatives in Context

Essential Standard / Enduring Understanding

Derivatives communicate rates in context: they describe motion, connect changing quantities, support local approximation, and justify limit procedures when conditions and units are interpreted correctly.

Unit Source Alignment

Framework Alignment
  • Framework Topics / Standards: 4.1: AP Topics 4.1, 4.3; 4.2: AP Topics 4.2; 4.3: AP Topics 4.4; 4.4: AP Topics 4.5; 4.5: AP Topics 4.6, 4.7.
  • Course-Specific Emphasis: College Board AP Calculus AB unit/topic sequence supported by teacher-created warm-ups, guided notes, Reading Apprenticeship routines, investigations, cooperative learning, AP Classroom practice, and structured activity-based review. Most sections use a flexible two-day rhythm with an optional third day for extension, FRQ writing, AP Classroom progress checks, reteaching, quizzes, or assessment practice; this plan does not convert that guidance into a required calendar.

Section 4.1: Meaning of Derivatives

AP Topics: 4.1, 4.3

Learning Target: Interpret $f$, $f'$, and $f''$ in context using appropriate units, rates, and verbal meaning.

I Can Statements

  • I can interpret $f$, $f'$, and $f''$ in context using appropriate units, rates, and verbal meaning.
  • I can write context-specific interpretations of derivatives.
  • I can compare meanings of $f$, $f'$, and $f''$ in one situation.

Key Vocabulary / Notation

  • rate of change
  • units
  • first derivative
  • second derivative

Key Representations

  • contextual verbal descriptions
  • function/derivative notation
  • tables and graphs with units

Common Misconceptions / Failure Points

  • Giving a derivative value without rate units.
  • Describing $f'$ as the original quantity rather than its rate of change.
  • Treating the second derivative as simply another velocity-like quantity without context.

Modeling / Application Opportunities

  • Write context-specific interpretations of derivatives.
  • Compare meanings of $f$, $f'$, and $f''$ in one situation.

Recurring Practice Opportunities

  • Interpretation: Connect the computed or inferred quantity to the variables/context and include units or sign meaning when the source situation provides them.
  • Notation / communication: Use the section’s limit, derivative, or integral notation precisely enough that the object, point/interval, and operation are unambiguous.
  • Justification: Support a conclusion with the relevant property, condition, representation, or calculation rather than an unsupported claim.

Section 4.5: Linearization and L'Hospital's Rule

AP Topics: 4.6, 4.7

Learning Target: Use local linearity for tangent-line approximation and apply L'Hospital's Rule only to appropriate indeterminate forms with required conditions.

I Can Statements

  • I can use local linearity for tangent-line approximation and apply L'Hospital's Rule only to appropriate indeterminate forms with required conditions.
  • I can estimate function values with a tangent model and discuss over/under behavior.
  • I can decide whether L'Hospital's Rule is applicable before using it.

Key Vocabulary / Notation

  • linearization
  • local linearity
  • tangent-line approximation
  • indeterminate form
  • L'Hospital's Rule

Key Representations

  • tangent line models
  • function and derivative values
  • limit forms
  • symbolic limits

Common Misconceptions / Failure Points

  • Using linearization far from the center without considering local accuracy.
  • Applying L'Hospital's Rule to a form that is not an appropriate indeterminate form.
  • Differentiating numerator and denominator when the rule conditions are not established.

Modeling / Application Opportunities

  • Estimate function values with a tangent model and discuss over/under behavior.
  • Decide whether L'Hospital's Rule is applicable before using it.

Recurring Practice Opportunities

  • Justification / conditions: Identify the mathematical condition or evidence that supports the conclusion rather than naming a rule or theorem without support.
  • Analytical strategy: Select and communicate a method from the structure of the expression/problem, then check for common procedural errors.
  • Notation / communication: Use the section’s limit, derivative, or integral notation precisely enough that the object, point/interval, and operation are unambiguous.
  • Modeling: Translate between the stated situation and a mathematical model/diagram, preserving the meaning of variables, dimensions, and relationships.

Unit Themes / Throughlines

Unit Themes / Throughlines
  • Attach units and contextual meaning to derivative values.
  • Use signs and multiple representations to reason about motion.
  • Translate verbal contexts into variable relationships before differentiating.
  • Interpret related-rate answers in terms of direction and units.
  • Check conditions before using local linearity or L'Hospital's Rule.

Reassessment / Alternate Forms: The framework does not prescribe a reassessment system. If an alternate form is used, preserve the same Mastery Goals, Learning Ladder, representation demands, and recurring-practice expectations while changing surface features and specific prompts.
