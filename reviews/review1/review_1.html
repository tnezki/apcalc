At a Glance

This unit is about deciding what a function is approaching, determining when a function is continuous, and using continuity to make guaranteed conclusions.

  • Limits from Graphs & Tables: Read one-sided and two-sided limits without confusing a limit with the actual function value.
  • Algebraic Limits: Use direct substitution when it works, and simplify indeterminate forms by factoring or rationalizing.
  • Continuity: Recognize removable and nonremovable discontinuities and choose missing values that make a function continuous.
  • Infinite Limits & Asymptotes: Connect infinite behavior to vertical asymptotes and end behavior to horizontal asymptotes.
  • Intermediate Value Theorem: Use continuity and sign/value changes to guarantee that a function takes particular values.
Non-calculator focus: Be ready to reason from structure, graphs, tables, exact values, factoring, and rationalizing.

Rules & Structures

Two-sided limit

$\lim_{x\to a}f(x)=L$

Only when both one-sided limits exist and equal $L$.

Continuity at $x=a$

$\lim_{x\to a}f(x)=f(a)$

The limit must exist, the function value must exist, and they must match.

Removable hole

$\lim_{x\to a}f(x)=L$

If the limit exists but $f(a)$ is missing or different, defining $f(a)=L$ removes the discontinuity.

Vertical asymptote

$\lim_{x\to a^-}f(x)=\pm\infty$

An infinite limit from at least one side signals a vertical asymptote at $x=a$.

Horizontal asymptote

$\lim_{x\to\pm\infty}f(x)=L$

The graph approaches the horizontal line $y=L$ in that direction.

IVT guarantee

$f(a)<N<f(b)$

If $f$ is continuous on $[a,b]$, then some $c$ between $a$ and $b$ has $f(c)=N$.

Review Focus 1

Limits from Graphs & Tables

↑ Top

I can: determine one-sided and two-sided limits from graphs and tables, including cases where the function value is different from the limit.

What to remember

  • Follow the graph toward the target $x$-value from the left and from the right.
  • The height of a filled point tells you $f(a)$; it does not automatically tell you $\lim_{x\to a}f(x)$.
  • A two-sided limit exists only when the left-hand and right-hand limits agree.
  • In a table, use values of $x$ close to the target from both sides. Do not rely on one isolated row.
  • For an expression such as $g(x+1)$, track what the inside input approaches.

Useful representations

Graphs with open/closed points, one-sided tables, shifted inputs, and combinations of functions.

Common traps

Using the filled dot

A limit describes nearby behavior, not necessarily the value at the point.

Checking only one side

One-sided agreement is required for a two-sided limit.

Reading the table too far away

Focus on values closest to the target from each side.

Missing an input shift

If $x\to1$, then $x+1\to2$.

Review Focus 2

Evaluating Limits Algebraically

↑ Top

I can: evaluate limits algebraically by using direct substitution, factoring, rationalizing, or piecewise reasoning.

What to remember

  • Try direct substitution first.
  • If substitution gives $0/0$, simplify the expression before evaluating the limit.
  • Factor differences of squares and cancel only common factors.
  • For square-root expressions, multiply by the conjugate when it removes the indeterminate form.
  • For absolute-value or piecewise expressions, compare the left-hand and right-hand behavior.

Examples of useful structure

$$\frac{x^2-a^2}{x-a}=x+a\quad(x\ne a)$$

$$\frac{\sqrt{x}-\sqrt{a}}{x-a}\cdot\frac{\sqrt{x}+\sqrt{a}}{\sqrt{x}+\sqrt{a}}=\frac{1}{\sqrt{x}+\sqrt{a}}$$

Common traps

Stopping at $0/0$

$0/0$ is an indeterminate form, not the value of the limit.

Canceling terms

Cancellation is valid for common factors, not pieces of a sum.

Ignoring the two sides

$|x|/x$ behaves differently to the left and right of zero.

Overcomplicating

If direct substitution gives a finite value, use it.

Review Focus 3

Continuity & Removable Discontinuities

↑ Top

I can: decide where a function is continuous, identify removable discontinuities, and choose missing function values or parameters to make a function continuous.

Continuity checklist at $x=a$

  1. Is $f(a)$ defined?
  2. Does $\lim_{x\to a}f(x)$ exist?
  3. Does $\lim_{x\to a}f(x)=f(a)$?

What to remember

  • A hole with the same approach from both sides is removable.
  • A jump is not removable because the one-sided limits disagree.
  • A vertical asymptote is not removable because the function does not approach a finite limit.
  • To fill a hole continuously, set the missing function value equal to the limit.
  • For a piecewise function with a parameter, match the branch limit to the defined value at the breakpoint.

Common traps

Calling every hole a limit failure

A removable hole can still have a perfectly good two-sided limit.

Using only $f(a)$

A defined point does not guarantee continuity.

Using only the limit

The limit and the function value must both exist and match.

Forgetting to simplify first

Factoring often reveals the value needed to fill a removable hole.

Review Focus 4

Infinite Limits & Asymptotes

↑ Top

I can: connect infinite one-sided limits to vertical asymptotes and limits at infinity to horizontal asymptotes.

What to remember

  • If $f(x)$ grows without bound as $x$ approaches $a$ from at least one side, $x=a$ is a vertical asymptote.
  • $\lim_{x\to a^-}f(x)=\infty$ does not force the right-hand limit to be $\infty$.
  • For rational functions at infinity, compare the highest powers.
  • If numerator and denominator have the same degree, the limit is the ratio of leading coefficients.
  • If the numerator degree is smaller, the limit is $0$.
  • A table with very large positive and negative $x$-values can provide evidence for a horizontal asymptote.

Common traps

Assuming both sides match

Infinite behavior may differ on opposite sides of an asymptote.

Looking at constant terms

At infinity, leading terms control a rational function's behavior.

Mixing vertical and horizontal

Finite $x$-targets relate to vertical asymptotes; $x\to\pm\infty$ relates to end behavior.

Treating $\infty$ as a number

It describes unbounded behavior, not a function value.

Review Focus 5

Intermediate Value Theorem

↑ Top

I can: use continuity and endpoint values to guarantee that a function takes an intermediate value, including guaranteeing zeros.

How to use IVT

  • Verify that the function is continuous on the interval being used.
  • Identify the two known function values.
  • Check whether the target value lies between them.
  • If it does, IVT guarantees at least one input $c$ between the endpoints where $f(c)$ equals the target.
  • A sign change guarantees at least one zero in that interval.
  • When several separate intervals show sign changes, count the guaranteed zeros interval by interval.

Key idea

If $f$ is continuous and $f(a)<0<f(b)$, then some $c$ in $(a,b)$ satisfies $f(c)=0$.

Common traps

Forgetting continuity

A sign change alone does not give an IVT guarantee unless continuity is known.

Claiming an exact location

IVT guarantees existence, not the exact value of $c$.

Claiming the maximum

Known table values do not prove a largest function value between them.

Target outside the range

IVT only guarantees values between the two known function values.
