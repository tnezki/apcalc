Limits from Graphs & Tables

1. The graph of $f$ approaches the open point $(2,3)$ from both sides, while the filled point at $x=2$ is $(2,5)$. What is $\lim_{x\to2}f(x)$?

  1. $3$
  2. $5$
  3. $2$
  4. The limit does not exist.

2. Suppose $\lim_{x\to0^-}g(x)=1$ and $\lim_{x\to0^+}g(x)=4$. Which statement is true?

  1. $\lim_{x\to0}g(x)=1$
  2. $\lim_{x\to0}g(x)=4$
  3. $\lim_{x\to0}g(x)=\frac52$
  4. $\lim_{x\to0}g(x)$ does not exist.

3. The table shows values of $h$ near $x=4$.

$x$3.93.993.9994.0014.014.1
$h(x)$6.206.026.0025.9985.985.80

Which conclusion is best supported?

  1. $\lim_{x\to4}h(x)=4$
  2. $\lim_{x\to4}h(x)=6$
  3. $h(4)=6$
  4. $\lim_{x\to6}h(x)=4$

4. Suppose $\lim_{x\to1}f(x)=2$ and $\lim_{t\to2}g(t)=-3$. What is $\lim_{x\to1}\left(2f(x)-g(x+1)\right)$?

  1. $-7$
  2. $1$
  3. $7$
  4. The limit does not exist.

Evaluating Limits Algebraically

5. What is $\displaystyle \lim_{x\to3}\frac{x^2-9}{x-3}$?

  1. $0$
  2. $3$
  3. $6$
  4. The limit does not exist.

6. What is $\displaystyle \lim_{x\to4}\frac{\sqrt{x+5}-3}{x-4}$?

  1. $\frac16$
  2. $\frac13$
  3. $3$
  4. $6$

7. What is $\displaystyle \lim_{x\to-2}\frac{|x+2|}{x+2}$?

  1. $-1$
  2. $0$
  3. $1$
  4. The limit does not exist.

8. What is $\displaystyle \lim_{x\to2}\frac{2x^2-x+1}{x+3}$?

  1. $1$
  2. $\frac75$
  3. $2$
  4. $\frac52$

Continuity & Removable Discontinuities

9. A function satisfies $\lim_{x\to1}f(x)=4$ but $f(1)=-2$. Which best describes the discontinuity at $x=1$?

  1. There is no discontinuity.
  2. It is removable.
  3. It is a jump discontinuity.
  4. It is an infinite discontinuity.

10. A function is continuous for all real numbers and is defined by $f(x)=\frac{x^2-25}{x-5}$ for $x\ne5$. What must $f(5)$ equal?

  1. $0$
  2. $5$
  3. $10$
  4. $25$

11. Let $$f(x)=\begin{cases}\frac{x^2-1}{x-1},&x\ne1\\b,&x=1\end{cases}$$ For what value of $b$ is $f$ continuous at $x=1$?

  1. $-1$
  2. $0$
  3. $1$
  4. $2$

12. A function has discontinuities only at $x=1$, $x=3$, and $x=4$. On which interval is the function continuous?

  1. $(0,2)$
  2. $(1,3)$
  3. $(2,4)$
  4. $(3,5)$

Infinite Limits & Asymptotes

13. If $\lim_{x\to5^-}f(x)=\infty$, which statement must be true?

  1. $\lim_{x\to5^+}f(x)=\infty$
  2. $f(5)$ is undefined.
  3. The graph has a vertical asymptote at $x=5$.
  4. The graph has a horizontal asymptote at $y=5$.

14. A rational function $g$ has the following values.

$x$-500-100-2020100500
$g(x)$-2.004-2.020-2.105-1.905-1.980-1.996

Which statement is best supported?

  1. The graph has a vertical asymptote at $x=-2$.
  2. The graph has a vertical asymptote at $x=0$.
  3. The graph has a horizontal asymptote at $y=-2$.
  4. The graph has a horizontal asymptote at $y=0$.

15. What is $\displaystyle \lim_{x\to\infty}\frac{3x^2-5}{2-6x^2}$?

  1. $-2$
  2. $-\frac12$
  3. $0$
  4. $\frac12$

16. What is $\displaystyle \lim_{x\to\infty}\frac{4x-1}{x^2+3}$?

  1. $0$
  2. $1$
  3. $4$
  4. The limit does not exist.

Intermediate Value Theorem

17. A function $f$ is continuous on $[1,4]$ with $f(1)=-3$ and $f(4)=5$. Which statement must be true?

  1. There is some $c$ in $(1,4)$ with $f(c)=0$.
  2. The maximum value of $f$ on $[1,4]$ is $5$.
  3. There is some $c$ in $(1,4)$ with $f(c)=8$.
  4. $f$ is increasing on $[1,4]$.

18. Selected values of a continuous function are shown.

$x$01234
$f(x)$3-2-145

What is the fewest possible number of zeros of $f$ on $[0,4]$?

  1. 0
  2. 1
  3. 2
  4. 3

19. A function $f$ is continuous on $[2,7]$ with $f(2)=6$ and $f(7)=1$. Which value is guaranteed to occur as $f(c)$ for at least one $c$ in $(2,7)$?

  1. $-1$
  2. $0$
  3. $4$
  4. $8$

20. A function $f$ is continuous on $[0,3]$, with $f(0)=1$ and $f(3)=6$. Which claim is not guaranteed by the Intermediate Value Theorem?

  1. There is a $c$ in $(0,3)$ with $f(c)=2$.
  2. There is a $c$ in $(0,3)$ with $f(c)=4$.
  3. There is a $c$ in $(0,3)$ with $f(c)=5$.
  4. There is a $c$ in $(0,3)$ with $f(c)=8$.
