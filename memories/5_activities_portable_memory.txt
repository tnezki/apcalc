GENERIC MATH / SCIENCE ACTIVITIES BUILD — PORTABLE MEMORY v1
================================================================

PURPOSE
-------
THIS FILE IS THE SINGLE SOURCE OF TRUTH FOR GENERIC MATH / SCIENCE ACTIVITY BUILDS.

The activity system is a flexible classroom menu, not a prescribed daily calendar.
Each section gets ONE reusable directions shell and TWO interchangeable canonical question sets:

  Set 1 = the section's approved Practice Set 2 Bank destination
  Set 2 = the section's approved Practice Set 3 Bank destination

The Bank is the canonical content authority. The activity build does NOT rewrite, adapt, simplify,
number-swap, or independently author the practice questions.

The activity package exists to transform the same approved Bank questions into useful classroom
structures:
  • projectable question / worked-solution decks
  • printable Stations
  • printable Find Someone Who worksheets
  • a reusable directions shell that links to either question set

The finished course is a rich menu of options. Resource existence does not mean the teacher must
use every activity, every section, or every day.

"BUILD," "CREATE," "MAKE," "GENERATE," "REBUILD," OR "REPAIR" means complete the full workflow
for the requested scope. A plan, partial HTML, or question list is not a completed build.

================================================================
LOCKED CORE DIRECTION WORDING
================================================================

Use the following wording as the reusable generic direction source. Update only the unit/section,
section title, and course-family labels where required.

WHITEBOARD INDY
Structure: Individual -> Independent practice
Setup: Each student gets a whiteboard and one marker.
Directions:
1. Notes are welcome.
2. Try something.
3. Write large and clearly — your work should be readable from across the room.
4. Use your resources: ask your partner first, then the teacher. Do not copy.
5. Mistakes are part of learning — fix them and discuss what went wrong.
Goal: Individual accountability + low-stakes problem entry

WHITEBOARD PARTNERS
Structure: Fast partner practice
Setup: Work with your partner. One whiteboard and one marker between you.
Directions:
1. Work with a partner.
2. Both students stay engaged.
3. Alternate who writes.
4. Write clearly and large.
5. Stay focused and collaborate.
6. Fix mistakes and discuss.
Goal: Engagement + quick feedback

RALLY COACH
Structure: Partner explanation + alternating roles
Setup: Sit with your partner. Each person needs one whiteboard and one marker.
Directions:
1. Work with a partner.
2. Partner A explains while Partner B writes.
3. Switch roles.
4. Check answers when directed by the teacher.
5. Rotate partners when directed.
Goal: Verbal reasoning + procedural / conceptual accuracy

SPEED DATING
Structure: Paired practice -> Timed rotation -> Strategy sharing
Setup: Partners. One whiteboard or blank paper for each person.
Directions:
1. Work with a partner on the projected problem — both students write on their own board or paper.
2. Compare strategies, evidence, representations, or methods before rotating.
3. After 3–4 minutes, one row shifts one seat to create a new pairing.
4. Bring your previous work and share your reasoning with your new partner.
5. Repeat across multiple problems and partner pairings.
Goal: Multiple representations + collaborative problem solving

SHOWDOWN
Structure: Indy -> Group comparison -> Consensus
Setup: Groups of 4. Each person has a whiteboard. Rotate the Captain each round.
Directions:
1. Each student solves the problem individually.
2. When prompted, students Showdown — reveal answers at the same time.
3. Discuss differences and justify reasoning.
4. The group agrees on a correct final answer or explanation.
5. Repeat.
Goal: Accountability + justification

THINK, TRADE, AGREE
Structure: Indy -> Group comparison -> Consensus
Setup: Groups of 4. Each person has a whiteboard.
Directions:
1. Teacher presents a problem.
2. Each student works independently first.
3. When everyone is ready, exchange boards with another student.
4. Discuss differences and justify reasoning.
5. Come to an agreement or ask the teacher for help.
6. Repeat the exchange with someone different.
Goal: Accountability + justification

ROUND TABLE
Structure: One step / contribution per student
Setup: Groups of 4. One whiteboard and one marker per group.
Directions:
1. Groups of 4 use one whiteboard and marker.
2. Each student completes one meaningful step, representation, observation, or reasoning move, then passes the board.
3. Rotate until the problem is complete.
4. Compare when the solution is shown.
5. Make sure every group member can explain the final reasoning.
Goal: Sequential reasoning + shared responsibility

STATIONS
Structure: Timed rotations
Setup: 8 stations around the room. Pick up a record sheet or work paper before you begin.
Directions:
1. Choose a starting station with no more than 4 students.
2. Work on the questions at that station.
3. Rotate when the teacher signals.
4. Do not all move to the same next station.
5. Keep your own record of work and corrections.
Goal: Repetition + varied problem exposure

FIND SOMEONE WHO
Structure: Movement + peer interaction
Setup: Keep your worksheet and pencil with you as you move around the room.
Directions:
1. Work alone first: skim every problem, then begin any problem you can solve.
2. Find a partner who is ready to share. Compare completed answers and discuss any that do not match.
3. Choose one problem that either of you left incomplete. Work through it together. Both partners record the reasoning on their own sheet.
4. Thank your partner and repeat with a different person.
5. Return to your seat with every problem completed and understood — not merely filled in.
Goal: Exposure to multiple explanations

MATHEMATICAL / CONCEPT HOT SEAT
Structure: Verbal description only -> Blind solving -> Role rotation
Setup: Groups. One whiteboard and one marker per member.
Directions:
1. One student per team sits facing away from the screen — the Hot Seat.
2. The teacher projects a problem that only teammates can see.
3. Teammates describe the problem using words only — no gestures and no copying the displayed work.
4. The Hot Seat student solves or explains based solely on the verbal description.
5. After solving, the student turns around and compares to the original problem.
6. Rotate the Hot Seat for each round.
Goal: Precise academic vocabulary + communication

RALLY COACH II
Structure: One teammate states the plan while the other group members record and execute it
Setup: Group of 4. Each person needs one whiteboard and one marker.
Directions:
1. Choose a Starter.
2. The Starter states the next step or reasoning move; teammates record and carry it out.
3. Group members may question or clarify the reasoning before moving on.
4. Check answers when directed by the teacher.
5. Rotate Starter.
Goal: Verbal reasoning + procedural / conceptual accuracy

MATH — TARSIA PUZZLE
Structure: Matching puzzle (self-checking)
Setup: Groups of 4. Use a teacher-prepared Tarsia puzzle generated from the section's Tarsia TXT.
Directions:
1. Match questions, expressions, representations, or answers on adjoining puzzle edges.
2. Continue until the pieces form the complete intended shape.
3. If the puzzle does not fit, locate and discuss the mismatch rather than forcing pieces together.
Goal: Error detection + pattern recognition

SCIENCE — BLOOKET / GAME REVIEW
Structure: Fast selected-response review
Setup: Individual devices or teacher-led team play using the section's Blooket export.
Directions:
1. Join the teacher's game when instructed.
2. Answer independently before discussing when the format permits.
3. Use missed questions as prompts for explanation, not just scorekeeping.
4. Pause for class discussion when a distractor reveals a common misconception.
Goal: Retrieval + misconception checking

MATH — DESMOS / DIGITAL MATH ACTIVITY
Structure: Individual or Partners -> Teacher-paced digital investigation
Setup: Individual or partner work on a computer/iPad.
Directions:
1. Open the teacher-selected activity using the posted link or code.
2. Read each prompt carefully; screens may ask you to type, sketch, move sliders, or plot points.
3. Work at the pace set by the teacher.
4. Stop and look up when the teacher pauses the class for discussion.
5. Show your thinking honestly in the activity responses.
Goal: Conceptual exploration + interactive sense-making

SCIENCE — SIMULATION / DIGITAL SCIENCE ACTIVITY
Structure: Individual or Partners -> Teacher-paced digital investigation
Setup: Individual or partner work on a computer/iPad using a teacher-selected simulation or digital model.
Directions:
1. Open the teacher-selected simulation or digital activity using the posted link or code.
2. Change only the variables or controls requested by the teacher or activity prompt.
3. Record observations, patterns, evidence, or measurements as directed.
4. Stop and look up when the teacher pauses the class for discussion.
5. Use the digital model as evidence; do not treat animation alone as an explanation.
Goal: Model-based exploration + evidence-based sense-making

MODE 2 — MAINTENANCE / REVISION
================================================================

Every maintenance request begins by inspecting the existing activity package and identifying
whether the requested change belongs at the Activity layer or upstream in the Bank.

ACTIVITY-LAYER CHANGES
----------------------
May be repaired directly when they do not alter canonical Bank content, for example:
  • broken internal links
  • wrong CSS path
  • missing direction page
  • direction wording / generic structure wording revision
  • Looks Like / Doesn't Look Like revision
  • wrong section title
  • question/solution page wrapper/layout issue
  • missing workspace in FSW when Bank question itself is unchanged
  • station grouping / duplex order issue
  • solution explanation improvement when canonical answer is unchanged
  • missing copied canonical figure when source asset already exists
  • packaging / folder structure problem

BANK-LAYER CHANGES
------------------
If the request changes any canonical PS2/PS3 question, answer, figure, mapping, destination,
or choice order, repair the Bank first.

Examples:
  • "Replace Activity 2 Question 6" -> resolve its PS3 Bank ID -> Bank maintenance first
  • "This activity question is wrong" -> Bank maintenance first
  • "Use a different graph in Set 1 Q8" -> Bank maintenance first if the graph is canonical
  • "Practice Set 3 should assess a different case" -> Bank maintenance first

Do not silently patch the activity copy and leave the Bank inconsistent.

MAINTENANCE WORKFLOW
--------------------
1. Inspect the existing unit/section package.
2. Recover affected source IDs from data-source-id / mapping.
3. Classify each requested change as Activity-layer or Bank-layer.
4. Ask only for genuinely missing upstream artifacts.
5. Preserve every unaffected file/content block.
6. Apply the smallest correct change.
7. Propagate the change to all affected activity representations:
     • question/solution deck
     • Stations
     • Find Someone Who
     • figure copies
8. Rerun the same QA passes as a full build for the affected scope.
9. Return a complete replacement ZIP/folder, not snippets.
10. Give a concise change report.

If a canonical Bank repair occurred, rebuild every downstream activity representation that uses
that Bank ID. Do not leave stale copies in another set/file.
