GENERIC MATH / SCIENCE PRACTICE SETS PORTABLE MEMORY — v1.0
=======================================================================

PURPOSE
-------
THIS FILE IS THE SINGLE SOURCE OF TRUTH FOR GENERIC MATH / SCIENCE
PRACTICE-SET BUILDS.

This PM is for Math and Science courses. STEM courses are separate.

The Bank is canonical. Practice Sets are a DOWNSTREAM ASSEMBLY stage.
The Practice Set builder does NOT author, rewrite, simplify, improve,
parallelize, or substitute academic questions. It locates the mapped Bank
items and copies their student-facing content VERBATIM.

The Bank has already authored:
  • Practice Set 1 — 20 unique items per section
  • Practice Set 2 — 20 unique items per section
  • Practice Set 3 — 20 unique items per section
  • Extra Practice — 20 unique items per section
  • CYU — 6 dedicated unique items per section
  • all canonical figures used by those items
  • all answers / solutions used for QA and exports

The Practice Set stage is responsible for:
  • correct routing
  • clean student HTML
  • workspace placement
  • copying approved Bank figures
  • Math Tarsia export OR Science Blooket export
  • traceability
  • packaging
  • QA

NO EXIT TICKETS ARE INCLUDED IN PRACTICE SETS.
Exit Tickets are built by a separate PM and separate resource.

BUILD ORDER IS NOT A TEACHING CALENDAR.
The existence of Practice Set 1, 2, 3, Extra Practice, or CYU does not mean
all resources must be used in class. They are a rich menu of options.

=======================================================================
VERBATIM BANK RULE
=======================================================================

Every Practice Set and CYU problem is copied VERBATIM from its mapped Bank item.

Copy the STUDENT-FACING body only:
  • prompt paragraphs
  • lists / problem parts
  • answer choices
  • table.values
  • figure references / graph blocks
  • claim/data/context material students need

Do NOT copy into student HTML:
  • visible Bank ID labels
  • Bank metadata blocks
  • solution / answer blocks
  • teacher notes
  • source_basis text

Do NOT:
  • paraphrase
  • change values
  • swap context
  • shorten wording
  • add a new part
  • remove a part
  • convert format
  • repair a distractor downstream

Allowed downstream-only transformations:
  • renumber visible problem number 1-20 / 1-6
  • wrap content in the locked Practice Set HTML shell
  • add workspace
  • copy canonical figures to local figures/
  • add hidden traceability attributes
  • Tarsia only: add | line breaks without changing mathematical content
  • Tarsia only: strip HTML wrappers to create concise edge text when the
    underlying words/math stay identical

If a mapped Bank problem is malformed, unsuitable, wrong, duplicated, or cannot
be rendered, STOP and identify it for Bank maintenance.

WORKSPACE RULES
=======================================================================

Use the current shared practice_set.css.

DEFAULT:
  non-multiple-choice problem → <div class="workspace ws-80"></div>
  multiple-choice problem     → <div class="workspace ws-10"></div>

ws-80 remains the default even for higher-DOK open response.

Increase beyond ws-80 only when the canonical problem clearly requires more
room, such as:
  • multi-part calculation
  • substantial written justification
  • student-drawn graph/model
  • large table completion
  • extended response

If an included blank graph/table is itself the primary workspace, use minimal
additional workspace unless student writing is still required.

Never shrink a genuine written-response task merely to save pages.

MATH BRANCH — TARSIA GENERATOR HTML
=======================================================================

MATH DOES NOT OUTPUT A TARSIA CSV BY DEFAULT.

Output:
  tarsia_[U]_[S]_practice_3.html

This is a section-specific, self-contained copy of the supplied
`tarsia_generator.html` template with the Practice Set 3 pairs PRELOADED.

The teacher opens the file and the puzzle is already populated. The generator's
Generate / Print / Shuffle controls remain available.

WHY 18 PAIRS:
The approved 16-triangle generator has exactly 18 interior shared edges.
Therefore one puzzle can use exactly 18 question/answer pairs.
Practice Set 3 still contains all 20 Bank questions in its normal HTML.

DEFAULT 18-ITEM TARSIA SELECTION:
  • all 5 Current PS3 items
  • all 5 Last PS3 items
  • 8 of the 10 Mastery PS3 items

Select the 8 Mastery items deliberately for:
  • broadest prerequisite coverage
  • clearest single answer
  • concise edge text
  • variety
  • minimal redundancy

Do not automatically use M01-M08 if M09/M10 create better breadth.
Record the 18 selected source IDs in the generator JavaScript as:

const TARSIA_SOURCE_IDS = [
  "U1-S1-PS3-C01",
  ...
];

This is hidden traceability, not visible puzzle text.

TARSIA CONTENT RULES:
  • Question and answer come from the SAME canonical PS3 Bank item.
  • Use the canonical Bank solution/answer — do not independently solve and
    substitute a different form.
  • Do not change numbers, operations, wording, or mathematical target.
  • `|` may be inserted to force a visual line break.
  • Target about 25 characters per visual line.
  • Use `$...$` for math.
  • Avoid figure-dependent items.
  • Avoid multiple-answer prompts.
  • Avoid long explanations as answers.

If fewer than 18 PS3 items are genuinely Tarsia-suitable:
  STOP and list the unsuitable Bank IDs. This is a Bank maintenance issue.

TARSIA GENERATOR TEMPLATE RULE:
Use the supplied generator as the UI/geometry authority.
Do not redesign the puzzle.

Replace only:
  • title-input default value
  • DEFAULT_CSV / pair-data block
  • TARSIA_SOURCE_IDS block if template includes it

The corrected generic generator should store pair data with a raw JavaScript
string so LaTeX backslashes survive:

const DEFAULT_CSV = String.raw`Question, Answer
Question, Answer`;

Do NOT place LaTeX such as `\tfrac` in a normal JavaScript string with an
unescaped backslash. In a normal JS string, `\t` becomes a tab and corrupts
`\tfrac`. String.raw avoids that failure.

Do not output a separate Tarsia CSV unless the user explicitly requests one.

  PS3 questions 1-20

Blooket import structure.

TIME LIMIT:
  DOK 1 → 30 sec

  1 / 2 / 3 / 4

single correct answer, or has malformed distractors:
  STOP and identify Bank ID(s) for repair.

=======================================================================
MAINTENANCE / REVISION MODE
=======================================================================

Every Practice Sets PM must support targeted repair.

Use Maintenance Mode when the user says things such as:
  • "Replace Practice Set 2 question 8."
  • "The workspace on 3.4 question 6 is too small."
  • "The Tarsia puzzle has a bad pair."
  • "The Blooket answer is wrong."
  • "This graph does not match the question."

WORKFLOW:

1. Inspect the existing Practice Set package first.
2. Resolve the affected visible problem to data-source-id.
3. Decide whether the defect is:

   PRACTICE-LAYER ONLY
     • workspace size
     • numbering
     • broken local path
     • title
     • ZIP packaging
     • Tarsia `|` line break
     • Tarsia pair order
     → fix Practice package directly.

   BANK-CANONICAL
     • question wording/content
     • values
     • answer/solution
     • distractors
     • DOK
     • Current/Last/Mastery routing
     • canonical figure
     • missing Bank item
     • Tarsia unsuitability of a PS3 Math item
     • Science PS3 not valid for Blooket
     → STOP and request/use Bank PM to repair Bank first.

4. Preserve every unaffected file/question.
5. After a Bank repair, rebuild only logically affected Practice artifacts.
6. Run the same QA passes.
7. Return a COMPLETE replacement ZIP, not a patch snippet.
8. Briefly report what changed and which Bank IDs were affected.

TARSIA DEPENDENCY:
If one selected PS3 Math Bank item changes, update:
  • Practice Set 3 HTML
  • Tarsia generator if that Bank ID is among the 18 selected
  • TARSIA_SOURCE_IDS remains synchronized.

BLOOKET DEPENDENCY:
If any Science PS3 item changes, update BOTH:
  • Practice Set 3 HTML
  • Blooket CSV
because the CSV must be an exact mirror.
