GENERIC MATH / SCIENCE PRACTICE SETS PORTABLE MEMORY — v8.0
=======================================================================

PURPOSE
-------
THIS FILE IS THE SINGLE SOURCE OF TRUTH FOR GENERIC MATH / SCIENCE
PRACTICE-SET BUILDS.

This PM is for Math and Science courses. STEM courses are separate.

The Bank is canonical. Practice Sets are a DOWNSTREAM ASSEMBLY stage.
The Practice Set builder does NOT author, rewrite, simplify, improve,
parallelize, or substitute academic questions. It locates the mapped Bank
items and copies their student-facing content VERBATIM.

The Bank has already authored:
  • Practice Set 1 — 20 unique items per section
  • Practice Set 2 — 20 unique items per section
  • Practice Set 3 — 20 unique items per section
  • Extra Practice — 20 unique items per section
  • CYU — 6 dedicated unique items per section
  • all canonical figures used by those items
  • all answers / solutions used for QA and exports

The Practice Set stage is responsible for:
  • correct routing
  • clean student HTML
  • workspace placement
  • copying approved Bank figures
  • Math Tarsia TXT export OR Science Blooket export
  • traceability
  • packaging
  • QA

NO EXIT TICKETS ARE INCLUDED IN PRACTICE SETS.
Exit Tickets are built by a separate PM and separate resource.

BUILD ORDER IS NOT A TEACHING CALENDAR.
The existence of Practice Set 1, 2, 3, Extra Practice, or CYU does not mean
all resources must be used in class. They are a rich menu of options.

=======================================================================
VERBATIM BANK RULE
=======================================================================

Every Practice Set and CYU problem is copied VERBATIM from its mapped Bank item.

Copy the STUDENT-FACING body only:
  • prompt paragraphs
  • lists / problem parts
  • answer choices
  • table.values
  • figure references / graph blocks
  • claim/data/context material students need

Do NOT copy into student HTML:
  • visible Bank ID labels
  • Bank metadata blocks
  • solution / answer blocks
  • teacher notes
  • source_basis text

Do NOT:
  • paraphrase
  • change values
  • swap context
  • shorten wording
  • add a new part
  • remove a part
  • convert format
  • repair a distractor downstream

Allowed downstream-only transformations:
  • renumber visible problem number 1-20 / 1-6
  • wrap content in the locked Practice Set HTML shell
  • add workspace
  • copy canonical figures to local figures/
  • add hidden traceability attributes
  • Tarsia TXT only: add | line breaks outside math without changing academic content
  • Tarsia TXT only: strip HTML wrappers to plain text while preserving the
    underlying words/math
  • Tarsia TXT only: normalize legacy raw mathematical vertical bars to semantic
    LaTeX such as \lvert...\rvert or \mid so the paste-ready text does not
    collide with the generator's | line-break marker

If a mapped Bank problem is malformed, unsuitable, wrong, duplicated, or cannot
be rendered, STOP and identify it for Bank maintenance.

=======================================================================
MATH BRANCH — TARSIA PASTE-READY TXT
=======================================================================

MATH DOES NOT OUTPUT OR MODIFY A TARSIA GENERATOR HTML.
MATH DOES NOT OUTPUT A TARSIA CSV BY DEFAULT.

Output:
  tarsia_[U]_[S]_practice_3.txt

This file is a simple UTF-8 text export of the section's 18 dedicated canonical
TAR Bank pairs. It is designed to be copied/pasted into the teacher's stable,
separately maintained master Tarsia generator.

WHY 18 PAIRS:
The approved 16-triangle Tarsia puzzle has exactly 18 interior shared edges.
Therefore the Bank provides exactly 18 dedicated Tarsia pairs per Math section.
Practice Set 3 remains completely independent and still contains its normal 20
canonical PS3 questions.

REQUIRED TARSIA INVENTORY PER SECTION:
  • U[U]-S[S]-TAR-C01 ... C05  = 5 Current
  • U[U]-S[S]-TAR-L01 ... L05  = 5 Last
  • U[U]-S[S]-TAR-M01 ... M08  = 8 Mastery

TXT FORMAT — EXACTLY ONE PAIR PER LINE:
  question, answer

Examples:
  Evaluate $\log_2 8$., $3$
  Solve $\lvert x-7\rvert=3$., $x=4$ or $x=10$
  Expand:|$\log(xy)$, $\log x+\log y$

FORMAT CONTRACT:
  • Exactly 18 nonblank lines. No header row. No comments. No Bank IDs.
  • Each line contains one question and one answer separated by the FIRST comma
    OUTSIDE $...$ math.
  • Question and answer come from the SAME canonical TAR Bank item.
  • Preserve canonical wording, values, mathematical target, and canonical answer.
  • Use normal LaTeX inside $...$.
  • A literal | OUTSIDE math is reserved for an intentional visual line break in
    the master Tarsia generator.
  • Mathematical vertical-bar notation in TAR content must use semantic LaTeX
    such as \lvert...\rvert, \mid, or \begin{vmatrix}...\end{vmatrix}; do
    not export raw mathematical | characters that the master generator could
    interpret as line breaks.
  • Target about 25 displayed characters per visual line where practical.
  • Do not add quotation marks around lines merely because commas occur inside math.
  • UTF-8 plain text only.

ALLOWED DOWNSTREAM NORMALIZATION:
The Practice Set builder may insert a | OUTSIDE math solely to create a sensible
visual line break. It may also normalize a mathematically equivalent raw vertical
bar to the semantic LaTeX command required by this TXT contract when an older Bank
item predates the rule. Do not otherwise rewrite, shorten, simplify, or alter the
canonical TAR item. Report repeated normalization as a Bank-maintenance issue so
future Banks are authored correctly.

HARD BANK BLOCKER:
If any of the 18 required TAR items is missing, ambiguous, duplicated, requires a
figure/table, is genuinely too long for the puzzle, lacks one canonical answer, or
cannot be represented safely as one `question, answer` line without academic
rewriting, STOP and list the exact Bank IDs for Bank maintenance.

NOT A BANK BLOCKER:
  • no Tarsia HTML exists in the output — that is now intentional
  • the teacher's local/master generator is separate from the curriculum package

TXT QA — REQUIRED FOR EVERY MATH SECTION:
  1. File exists with exact required filename.
  2. Exactly 18 nonblank lines.
  3. Inventory = 5 Current + 5 Last + 8 Mastery.
  4. Every mapped TAR Bank ID appears exactly once in the export plan.
  5. Every line parses into nonblank question + nonblank answer at the first comma
     outside math.
  6. No extra outside-math comma appears in the question before the delimiter.
  7. No raw mathematical | survives inside $...$; semantic LaTeX vertical-bar
     notation is used instead.
  8. Any | outside math is intentional line-break formatting only.
  9. No figure/table/HTML markup is present.
 10. All 18 canonical answers remain unique within the section.
 11. The file opens as normal UTF-8 text and can be pasted directly into the
     stable master Tarsia generator.

Do not output a Tarsia HTML or separate Tarsia CSV unless the user explicitly
requests one.

  1 / 2 / 3 / 4
