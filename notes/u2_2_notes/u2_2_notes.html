Limits Involving Infinity

Infinity describes a direction of behavior, not a number to substitute.

What you'll learn about

Learning Target: Analyze end behavior and infinite limits and connect them to asymptotes.

  • I can evaluate finite limits as $x\to\infty$ and $x\to-\infty$.
  • I can use end-behavior models to identify horizontal or slant asymptotes.
  • I can interpret one-sided infinite behavior and identify vertical asymptotes.
...and why

Limits involving infinity describe what a function does far beyond the visible graph and near inputs where the function grows without bound.

Section Introduction

Two different ways infinity enters a limit

There are two distinct ideas in this section. We can let the input move farther and farther to the right or left and ask what the function approaches, or we can let the input approach a fixed value while the output grows without bound.

For rational functions, the highest-power terms control long-run behavior. End-behavior models make that comparison visible and help identify horizontal or slant asymptotes.

Near a vertical asymptote, one-sided limits matter because the function may increase or decrease without bound differently on the two sides.

Keep the two roles of infinity separate: sometimes the input goes to infinity; other times the output does.

DefinitionHorizontal Asymptote

The line $y=b$ is a horizontal asymptote of the graph of a function $y=f(x)$ if either

$$\lim_{x\to\infty}f(x)=b \qquad\text{or}\qquad \lim_{x\to-\infty}f(x)=b.$$
Theorem 5Properties of Limits as $x\to\pm\infty$

If $L$, $M$, and $k$ are real numbers and $\displaystyle\lim_{x\to\pm\infty}f(x)=L$ and $\displaystyle\lim_{x\to\pm\infty}g(x)=M$, then:

  1. Sum Rule: $\displaystyle \lim_{x\to\pm\infty}[f(x)+g(x)]=L+M$
  2. Difference Rule: $\displaystyle \lim_{x\to\pm\infty}[f(x)-g(x)]=L-M$
  3. Product Rule: $\displaystyle \lim_{x\to\pm\infty}[f(x)g(x)]=LM$
  4. Constant Multiple Rule: $\displaystyle \lim_{x\to\pm\infty}[k f(x)]=kL$
  5. Quotient Rule: $\displaystyle \lim_{x\to\pm\infty}\frac{f(x)}{g(x)}=\frac{L}{M}$, provided $M\ne0$
  6. Power Rule: If $r$ and $s$ are integers with $s\ne0$, then $\displaystyle \lim_{x\to\pm\infty}[f(x)]^{r/s}=L^{r/s}$, provided $L^{r/s}$ is a real number.
DefinitionEnd Behavior Model

The function $g$ is

  1. a right end behavior model for $f$ if and only if $\displaystyle\lim_{x\to\infty}\frac{f(x)}{g(x)}=1$;
  2. a left end behavior model for $f$ if and only if $\displaystyle\lim_{x\to-\infty}\frac{f(x)}{g(x)}=1$.

DefinitionVertical Asymptote

The line $x=a$ is a vertical asymptote of the graph of a function $y=f(x)$ if a one-sided limit at $a$ is unbounded; that is, if at least one of

$$\lim_{x\to a^+}f(x) \qquad\text{or}\qquad \lim_{x\to a^-}f(x)$$

is $+\infty$ or $-\infty$.
