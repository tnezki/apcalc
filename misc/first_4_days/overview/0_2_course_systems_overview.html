AP Calculus AB · 0.2 Course Systems

Course Systems Overview

Know where the work lives, what each resource is for, and what a useful mathematical record looks like.

Daily Flow

  • Welcome / Learning Target
  • Warm-Up
  • Notes, Investigation, or Activity
  • Practice
  • Exit / evidence when assigned

Notability

  • Keep a working copy you can find again.
  • Write enough steps to understand your own reasoning later.
  • Draw directly on graphs when a representation is part of the mathematics.

AP Calculus Habits

  • Use precise notation.
  • Show the point, interval, units, or graph evidence supporting an answer.
  • Expect multiple representations: equations, tables, graphs, and words.

If You Miss Class

  • Start with the course agenda.
  • Open the named resource for the day.
  • Use teacher-provided keys/guides only as directed.
  • Ask what evidence needs to be completed or collected.
