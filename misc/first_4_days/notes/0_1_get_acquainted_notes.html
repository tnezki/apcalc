Idea 1 — From Secant Slope to Tangent Slope

A secant line uses two points. To estimate the instantaneous rate of change at one target point, keep that point fixed and move the second point closer. If the secant slopes begin to settle near one value, that value is a reasonable tangent-slope estimate.

Example 1

For $f(x)=x^2$ at $x=2$, use the target point $(2,4)$ and the second point $(3,9)$. Find the secant slope.

You Try It 1

Keep $(2,4)$ fixed. Use $(2.5,6.25)$, then $(2.1,4.41)$. Find both secant slopes. What tangent slope do they suggest?

Example 2

A cubic curve passes through $P=(1,2)$. Nearby secant slopes are $4.8,\ 4.3,\ 4.08,\ 4.01$. Estimate the tangent slope and write an estimated tangent line using $y=m(x-x_1)+y_1$.

You Try It 2

A curve passes through $(-1,3)$. Nearby secant slopes are $-2.6,\ -2.2,\ -2.05,\ -2.01$. Estimate $m$ and write an estimated tangent-line equation.

Idea 2 — LRAM: Left Rectangles Approximate Area

Split the interval into equal widths. For each rectangle, use the function value at the left endpoint as the height. Then add rectangle areas: $\text{LRAM}=\sum (\Delta x)(\text{left height})$.

Summary

  • Instantaneous rate is a local slope idea; nearby secants give evidence for the tangent slope.
  • A tangent-line estimate needs a point and a slope: $y=m(x-x_1)+y_1$.
  • LRAM uses left endpoints for rectangle heights and adds $\Delta x\cdot\text{height}$.
Summary notes / questions / connections

Common Mistakes

  • Moving both secant points instead of keeping the target fixed.
  • Using the wrong coordinates in point-slope form.
  • Using right endpoints when the problem asks for LRAM.
  • Forgetting that a Riemann sum is an estimate.
