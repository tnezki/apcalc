Warm-Up 2 · Functions

Review function evaluation and simple compositions.

Name Date
Warm-Up: Evaluate first; then substitute carefully into the next function.

1. Function values

Let $f(x)=x^2-3x+2$. Find $f(4)$ and $f(-1)$.

2. Composition

Let $f(x)=2x+1$ and $g(x)=x^2-4$. Find $(f\circ g)(3)$.

3. Composition in the other order

Using the same functions, find $(g\circ f)(1)$.
