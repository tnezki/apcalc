Investigation · Guess the Tangent / Build LRAM

A visual 30-minute investigation using simple quadratic and cubic graphs.

Investigation · about 30 minutes
Work visually. Draw, record, test, compare, and explain. Ordinary Desmos calculator use is optional; no class code is required.

Part A — Guess the Tangent Line

For each function, identify the exact target point $(x_1,y_1)$. Then estimate a tangent slope $m$ visually or with nearby secants. Write $y=m(x-x_1)+y_1$ and, if using Desmos, adjust $m$ until the line appears tangent.
