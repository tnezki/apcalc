Whiteboard Indy

Graphical Rate + LRAM
← Activity Options
Structure

Individual → independent practice

Setup

Each student has a whiteboard and marker.

Directions
  1. Choose a question from Set 1 or Set 2.
  2. Try it independently before asking for an answer.
  3. Write large enough for the teacher to read across the room.
  4. Show the target point, slope work, or rectangle setup—not just the final number.
  5. Hold up your board when asked and be ready to explain one decision.
Goal: Independent attempt + visible calculus thinking
Question sets

Set 1 · Set 2

Looks Like Success
  • Everyone has visible work.
  • The target point/left endpoints are marked when relevant.
  • Mistakes are corrected with an explanation.
Doesn’t Look Like
  • Waiting with a blank board.
  • Copying another board.
  • Showing only a final answer.

Whiteboard Partners

Graphical Rate + LRAM
← Activity Options
Structure

Partners → solve, compare, explain

Setup

Each partner has a board and marker.

Directions
  1. Both partners attempt the problem independently.
  2. Compare the point, slope setup, or LRAM setup.
  3. If answers differ, find the first place the work differs.
  4. Revise your own board after discussion.
  5. Either partner should be able to explain the pair's reasoning.
Goal: Independent thinking + comparison
Question sets

Set 1 · Set 2

Looks Like Success
  • Both partners have work.
  • Differences lead to mathematical discussion.
  • Either partner can explain.
Doesn’t Look Like
  • One partner does all the work.
  • Erasing differences without discussing them.
  • Only comparing final answers.

Rally Coach

Graphical Rate + LRAM
← Activity Options
Structure

Partners → Solver + Coach

Setup

Partners share a question set. One begins as Solver, one as Coach.

Directions
  1. Solver works one step at a time and explains aloud.
  2. Coach checks the target point, secant slope, left endpoint, or $\Delta x$.
  3. Coach asks questions or gives a hint but does not take over.
  4. Finish the question, then switch roles.
  5. Continue alternating.
Goal: Explanation + supportive checking
Question sets

Set 1 · Set 2

Looks Like Success
  • Solver narrates choices.
  • Coach asks evidence-based questions.
  • Roles switch every problem.
Doesn’t Look Like
  • Coach solves the problem.
  • Solver works silently.
  • One person stays in one role.

Speed Dating Math

Graphical Rate + LRAM
← Activity Options
Structure

Timed partner rounds → explain, compare, rotate

Setup

Students face a partner with a board or paper; teacher controls rotation.

Directions
  1. Attempt the displayed question.
  2. Compare your graphical or numerical evidence.
  3. Each person explains one useful step.
  4. Ask one clarifying question if the work differs.
  5. Rotate only when the teacher signals.
Goal: Repeated explanation + new mathematical partners
Question sets

Set 1 · Set 2

Looks Like Success
  • Both students attempt.
  • Conversation reaches the reasoning.
  • Rotation happens on signal.
Doesn’t Look Like
  • Waiting for a partner to solve.
  • Only saying an answer.
  • Moving before the signal.

Showdown

Graphical Rate + LRAM
← Activity Options
Structure

Individual think → simultaneous reveal → team discussion

Setup

Groups of 3–4; each student has a board.

Directions
  1. Solve independently and keep the board hidden.
  2. On the signal, reveal all boards together.
  3. Compare target points, slopes, endpoints, and totals.
  4. If results differ, identify the first mathematical disagreement.
  5. Correct your own board and prepare one team explanation.
Goal: Independent accountability + error analysis
Question sets

Set 1 · Set 2

Looks Like Success
  • Everyone commits before reveal.
  • Differences are explained.
  • Each student corrects their own work.
Doesn’t Look Like
  • Peeking before reveal.
  • Voting without checking work.
  • One student fixes everyone else's work.

Think, Trade, Agree

Graphical Rate + LRAM
← Activity Options
Structure

Think alone → trade reasoning → agree

Setup

Partners each have their own work surface.

Directions
  1. Solve independently.
  2. Trade explanations, not papers.
  3. Ask at least one clarifying question.
  4. Agree on a defensible setup before comparing final numbers.
  5. Revise your own work if your reasoning changes.
Goal: Reasoning before agreement
Question sets

Set 1 · Set 2

Looks Like Success
  • Both ideas are heard.
  • Evidence determines agreement.
  • Revisions have a reason.
Doesn’t Look Like
  • One answer automatically wins.
  • No questions are asked.
  • Changing work without understanding why.

Round Table

Graphical Rate + LRAM
← Activity Options
Structure

Group sequence → each person contributes

Setup

Groups of 3–4 share one large board or paper.

Directions
  1. Student 1 identifies the target point or interval.
  2. Student 2 adds the slope/width setup.
  3. Student 3 completes the next mathematical step.
  4. Student 4 checks and explains the full solution.
  5. Rotate who starts on the next question.
Goal: Shared solution with accountable contributions
Question sets

Set 1 · Set 2

Looks Like Success
  • Every person contributes.
  • Each addition connects to prior work.
  • The group checks the full chain.
Doesn’t Look Like
  • One person writes everything.
  • Passing without contributing.
  • Adding steps that are not explained.

Mathematical Hot Seat

Graphical Rate + LRAM
← Activity Options
Structure

One explains → team questions → rotate

Setup

Groups choose one speaker for the first problem.

Directions
  1. Hot-seat student explains the solution without teammates feeding answers.
  2. Teammates ask for evidence: point, slope, endpoint, width, or graph feature.
  3. Speaker may revise after a question.
  4. Team names one strong part and one possible improvement.
  5. Rotate the hot seat.
Goal: Defend a solution with evidence
Question sets

Set 1 · Set 2

Looks Like Success
  • Speaker explains decisions.
  • Questions point to evidence.
  • Role rotates.
Doesn’t Look Like
  • Teammates whisper answers.
  • Questions are only yes/no.
  • Same speaker every time.

Stations

Graphical Rate + LRAM
← Activity Options
Structure

Small groups → focused tasks → rotate

Setup

Use the printable Set 1 or Set 2 Stations pages.

Directions
  1. Start at the assigned station.
  2. Every student records the setup and result.
  3. Compare before leaving the station.
  4. Leave a readable representation or explanation.
  5. Rotate when signaled and continue.
Goal: Focused repetition + visible representations
Question sets

Set 1 · Set 2

Looks Like Success

  • Groups finish a meaningful step.
  • Rotation is orderly.
Doesn’t Look Like
  • One recorder for everyone.
  • Skipping graph/setup work.
  • Rotating before the signal.

Find Someone Who

Graphical Rate + LRAM
← Activity Options
Structure

Individual sheet → many short partner explanations

Setup

Each student needs the Find Someone Who handout.

Directions
  1. Choose one open problem and find a partner.
  2. Both people solve or explain before anyone signs.
  3. Record reasoning you understand—not copied work.
  4. Get a signature only after you can explain the result.
  5. Find a different partner for the next problem.
Goal: Multiple partners + accountable understanding
Question sets

Set 1 · Set 2

Looks Like Success
  • Explanations happen before signatures.
  • Students can explain what they recorded.
  • Partners change.
Doesn’t Look Like
  • Signature collecting without math.
  • Copying completed work.
  • Staying with one partner.
