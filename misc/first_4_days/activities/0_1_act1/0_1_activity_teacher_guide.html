AP Calculus AB · First 4 Days · Teacher

Activity — Teacher & Student Moves

Two independent review sets used through the same participation structures.

Set 1 — Unit Circle Review

Set 1 reviews radians, directed angles, unit-circle locations, and exact trigonometric values. Preserve student explanation of how an angle or exact value was determined rather than treating the set as answer-only recall.

Set 2 — Parent Function Transformations

Core form: $g(x)=a f(x-h)+k$.

Set design: Problems 1–4 keep the short transformation-language warm-up. Problems 5–17 are equation → graph. Problems 18–30 are graph → equation.

  • Teacher: ask students to identify the parent function first, then interpret $a$, $h$, and $k$ before expanding or plotting.
  • Student: connect the equation to the parent graph, map key points/features, graph accurately, and reverse the process by writing an equation from a supplied graph.
  • Important: the set intentionally omits logarithmic and step functions. It includes linear, quadratic, absolute value, cubic, square root, cube root, reciprocal, exponential, sine, and cosine families.
  • Graphing: graph prompts use the existing misc/printables/plane.png asset. Encourage students to mark key points/features before drawing the full shape.

Participation moves

  • Whiteboards: scan for a visible setup or representation before calling on a speaker.
  • Rally Coach: coaches ask what the parent function is and what each parameter changes rather than giving the next step.
  • Showdown: preserve private think time before reveal.
  • Stations: require a readable equation, key feature, point mapping, or graph before rotation.
  • Find Someone Who: remains a separate First 4 Days review handout; signatures come only after an explanation the student understands.
Set structure: Set 1 and Set 2 are independent First 4 Days review pools. Set 2 is purpose-authored for parent-function transformations and is not tied to the current Practice / Extra Practice files.
