Practice Key

Answers for Practice 1, Practice 2, and Extra Practice.

Practice 1

P1-1: secant slopes $3,2.5,2.1\to2$.
P1-2: tangent slope $\approx-2$; through $(-1,-1)$: $y+1=-2(x+1)$.
P1-3: $m\approx3$; the values stabilize near 3.
P1-4: $\Delta x=1$; heights $0,1,4,9$; LRAM $=14$.
P1-5: $1(2+5+7+6)=20$.
P1-6: mostly below for an increasing positive function because each left-endpoint height is smaller than later values in its subinterval.

Practice 2

P2-1: slopes $2.5,2.25,2.05\to2$.
P2-2: $m\approx4$; $y-3=4(x-1)$.
P2-3: Student B, assuming accurate coordinates/calculation, because the second points are closer to the target. Still check both points, arithmetic, scale, and whether slopes are stabilizing.
P2-4: $\Delta x=0.5$; LRAM $=12.75$.
P2-5: $2(3+5+4+8)=40$.
P2-6: gallons; an estimated accumulated amount of fluid.

Extra Practice

EP-1: slopes $-1,-1.5,-1.9\to-2$.
EP-2: tangent slope $\approx3$; $y+1=3(x+1)$.
EP-3: about $-4$.
EP-4: $\Delta x=1$; heights $1,1.25,2,3.25,5,7.25$; LRAM $=19.75$.
EP-5: $1.5(4+6+5+3)=27$.
EP-6: meters; estimated displacement over the time interval (when using signed velocity).
