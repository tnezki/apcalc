0.1 Unit Circle Review — Practice Set

Practice 1 — Build the Ideas

1. Draw the directed angle $\frac{\pi}{3}$ in standard position. Show the initial side and terminal side.

2. Draw the directed angle $-\frac{3\pi}{4}$ in standard position. Show the direction of rotation.

3. Draw the directed angle $\frac{13\pi}{4}$ in standard position. Show the complete rotation(s) before the terminal side.

4. Find the angle in $[0,2\pi)$ that is coterminal with $-\frac{5\pi}{6}$.

5. Find the angle in $[0,2\pi)$ that is coterminal with $\frac{17\pi}{6}$.

6. Find the reference angle for $\frac{13\pi}{6}$.

7. Give the exact unit-circle coordinate $(\cos\theta,\sin\theta)$ for $\theta=\frac{5\pi}{6}$.

8. Evaluate all six trig functions exactly for $\theta=\frac{2\pi}{3}$: $\sin\theta,\cos\theta,\tan\theta,\csc\theta,\sec\theta,\cot\theta$.

9. Evaluate all six trig functions exactly for $\theta=\frac{7\pi}{4}$.

10. Evaluate all six trig functions exactly for $\theta=\frac{3\pi}{2}$. Identify any undefined values.

11. Evaluate all six trig functions exactly for $\theta=-\frac{\pi}{6}$.

12. Evaluate all six trig functions exactly for $\theta=\frac{5\pi}{4}$.

0.1 Unit Circle Review — Practice Set

Practice 2 — Parallel Version

1. Draw the directed angle $\frac{5\pi}{4}$ in standard position. Show the initial side and terminal side.

2. Draw the directed angle $-\frac{\pi}{3}$ in standard position. Show the direction of rotation.

3. Draw the directed angle $\frac{19\pi}{6}$ in standard position. Show the complete rotation(s) before the terminal side.

4. Find the angle in $[0,2\pi)$ that is coterminal with $-\frac{11\pi}{6}$.

5. Find the angle in $[0,2\pi)$ that is coterminal with $\frac{23\pi}{4}$.

6. In which quadrant does the terminal side of $\frac{25\pi}{6}$ lie?

7. An angle $\theta$ in $[0,2\pi)$ has unit-circle coordinate $\left(\frac{\sqrt3}{2},-\frac12\right)$. Find $\theta$.

8. Evaluate all six trig functions exactly for $\theta=\frac{5\pi}{6}$.

9. Evaluate all six trig functions exactly for $\theta=\frac{11\pi}{3}$.

10. Evaluate all six trig functions exactly for $\theta=-\frac{3\pi}{4}$.

11. Evaluate all six trig functions exactly for $\theta=\frac{\pi}{2}$. Identify any undefined values.

12. Evaluate all six trig functions exactly for $\theta=\frac{7\pi}{6}$.
