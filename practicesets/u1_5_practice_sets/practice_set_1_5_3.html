1. Use the graph to describe the asymptotic behavior.

  1. Identify the vertical asymptote.
  2. Identify the horizontal asymptote.
  3. Write one infinite-limit statement and one limit-at-infinity statement supported by the graph.

2. For $f(x)=3+\frac{8}{x-1}$:

  1. Find $\lim_{x\to\infty}f(x)$.
  2. Find $\lim_{x\to-\infty}f(x)$.
  3. State the horizontal asymptote and explain how the two limits support it.

3. A continuous function on $[1,5]$ satisfies $f(1)=-4$ and $f(5)=6$.

  1. Use the Intermediate Value Theorem to decide whether some $c$ must satisfy $f(c)=2$.
  2. Decide whether IVT guarantees a point where $f(c)=9$.
  3. State the hypothesis and between-values condition used.

4. Compare the two statements.

  1. $\lim_{x\to2^+}f(x)=+\infty$
  2. $\lim_{x\to\infty}f(x)=2$

For each statement, describe what happens to the input and what happens to the output. Then identify the type of asymptote suggested.

6. Let $f(x)=\begin{cases}4x-1,&x\lt2\k,&x=2\x+5,&x\gt2\end{cases}$.

  1. Find both one-sided limits at $2$.
  2. Determine whether a value of $k$ can make $f$ continuous.
  3. State that value if it exists.

7. A function is continuous on $(a,b)$.

  1. What additional one-sided conditions are needed at $a$ and $b$ for continuity on $[a,b]$?
  2. Explain why the directions are different at the two endpoints.

8. A function has $f(3)=2$, $\lim_{x\to3^-}f(x)=2$, and $\lim_{x\to3^+}f(x)=5$.

  1. Does the two-sided limit exist?
  2. Is the function continuous at $3$?
  3. Identify the first continuity condition that fails.

9. A graph has an open circle at $(1,4)$ and a filled point at $(1,-2)$, while the curve approaches $4$ from both sides.

  1. Classify the discontinuity.
  2. State the limit and function value.
  3. Describe the single change that would make the function continuous.

10. At $x=-1$, a function grows without bound from one side and decreases without bound from the other.

  1. Classify the discontinuity.
  2. State what type of asymptote is present.
  3. Explain why a finite function value at $x=-1$ would not repair the discontinuity.

  1. Find both solutions.

14. For $q(x)=x^2+6x$, find the average rate of change on $[4,7]$.

  1. Evaluate both endpoint outputs.

  3. Interpret the sign of the result.

  1. Write the average-rate-of-change quotient before simplifying.
