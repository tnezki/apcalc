AP Calculus AB · Textbook Section 2.3

Continuity · Practice 1

Intro

1. State the three conditions required for f to be continuous at x=c.

2. If \(f(x)=\frac{x^2-4}{x+2}\) for x≠-2 and f is continuous for all real numbers, find f(-2).

3. For what positive value of a is \(f(x)=\frac{(x-1)(x^2-4)}{x^2-a}\) continuous for all real x?

4. For \(h(x)=\frac{x^2+5x+6}{x^2+7x+10}\), identify the removable discontinuity.

5. For the same h, find the vertical and horizontal asymptotes.

6. Explain why \(f(x)=x^2-4x+3\) has a zero in [2,4].

7. Identify the discontinuity of \(y=1/(x+2)^2\).

8. Identify the discontinuity of \(y=x/|x|\).

Review

9. State the interval on which \(y=\ln(x+1)\) is continuous.

10. For \(f(x)=3-x\) if x<2 and \(f(x)=x/2+1\) if x>2, classify the discontinuity at 2.

11. For \(f(x)=3-x\) if x<2, f(2)=2, and f(x)=x/2 if x>2, classify the discontinuity at 2.

12. For \(f(x)=1/(x-1)\) if x<1 and \(f(x)=x^3-2x+5\) if x≥1, classify the discontinuity at 1.

13. For \(f(x)=1-x^2\) when x≠-1 and f(-1)=2, classify the discontinuity.

14. Give a continuous extension value at x=-3 for \(f(x)=\frac{x^2-9}{x+3}\).

15. Give a continuous extension value at x=0 for \(f(x)=\frac{\sin4x}{x}\).

16. Give a continuous extension value at x=4 for \(f(x)=\frac{x-4}{\sqrt{x}-2}\).

Mastery

17. Find a so \(f(x)=x^2-1\) for x<3 and \(f(x)=2ax\) for x≥3 is continuous.

18. Find a so \(f(x)=2x+3\) for x≤2 and \(f(x)=ax+1\) for x>2 is continuous.

19. A continuous function has f(1)=-2 and f(5)=7. State the strongest IVT conclusion about roots on [1,5].

20. A function on [0,4] has a jump at x=2, with f(0)=-3 and f(4)=5. Can the IVT be used to guarantee f(c)=0? Explain.

21. Which condition is NOT required for continuity at x=c?

  1. f(c) is defined
  2. The two-sided limit exists
  3. The limit equals f(c)
  4. f has a horizontal tangent at c

22. Suppose f is continuous at 2 and g is continuous at f(2)=5. Explain why \(g(f(x))\) is continuous at 2.

23. A polynomial f satisfies f(0)=2 and f(2)=-5. Does IVT guarantee a solution to f(x)=1 on (0,2)? Justify.

24. A rational function has a removable hole at x=2 and a vertical asymptote at x=5. Which discontinuity can be repaired by changing one function value, and why?
