AP Calculus AB · Textbook Section 2.3

Continuity · Practice 3 · Activity Set 2 Review

Intro

1. Classify a discontinuity where one-sided limits are 2 and 7.

2. Classify persistent oscillation near a point with no single limiting value.

3. If g(-1)=3 and the two-sided limit at -1 is 4, is g continuous there?

4. A rational function is given. Where is it continuous?

5. Find k so g(x)=2kx-1 for x<2 and g(x)=7 for x≥2 is continuous.

6. For \(g(x)=\frac{x^2-25}{x-5}\), what value at x=5 repairs the hole?

7. Before using IVT to guarantee a zero, what two facts should be written?

8. If g is continuous on [-2,3] with endpoint values -5 and 1, which values are guaranteed?

Review

9. Determine intervals of continuity for \(g(x)=\frac{x-4}{(x+1)(x-5)}\).

10. Determine intervals of continuity for \(g(x)=\sqrt{x+2}\).

11. For \(g(x)=\frac{x^2-9}{x^2-2x-3}\), classify denominator zeros.

12. Find k so \(g(x)=2x+k\) for x≤1 and \(g(x)=x^2+4\) for x>1 is continuous.

13. A function is continuous on [-3,2], g(-3)=7 and g(2)=-2. Justify g(c)=1.

14. Does IVT guarantee uniqueness of the target value?

15. If f and g are continuous at c and g(c)≠0, is f/g continuous at c?

16. A function has a jump at c. Can changing only f(c) make it continuous?

Mastery

17. Find a so \(g(x)=\frac{x^2-a^2}{x-a}\) and g(a)=14 is continuous.

18. A continuous function has endpoint values of opposite sign. Evaluate the claim that there is a unique root.

19. Suppose g is continuous on [-1,2], g(-1)=5, and g never equals 0. What sign must g(2) have?

20. For \(g(x)=\frac{x^2-x-6}{x-3}\), define g(3) for continuity.

21. A function has f(c)=7 but left/right limits 5 and 7. Which condition fails?

22. Verify continuity of \(g(x)=x^{2/3}\) at 0.

23. A continuous function has endpoint values -3 and 5. Name two target outputs IVT guarantees.

24. Construct a piecewise function with a jump at x=0 that cannot be fixed by changing f(0).
