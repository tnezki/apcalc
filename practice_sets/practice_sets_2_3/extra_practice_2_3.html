AP Calculus AB · Textbook Section 2.3

Continuity · Extra Practice

Intro

1. Classify a discontinuity where both one-sided limits equal 4 but f(c) is undefined.

2. Classify a discontinuity where f(x) grows without bound near x=3.

3. If f(2)=5 and \(\lim_{x\to2}f(x)=5\), what continuity conclusion follows?

4. A polynomial is given. On what intervals is it continuous?

5. Find k so f(x)=kx+1 for x<1 and f(x)=4 for x≥1 is continuous.

6. For \(f(x)=\frac{x^2-1}{x-1}\), what value at x=1 makes a continuous extension?

7. What hypotheses must be checked before applying IVT on [a,b]?

8. If f is continuous on [1,4], f(1)=2, f(4)=9, which values N are guaranteed to occur?

Review

9. Determine intervals of continuity for \(f(x)=\frac{x+1}{(x-2)(x+3)}\).

10. Determine intervals of continuity for \(f(x)=\ln(x-4)\).

11. For \(f(x)=\frac{x^2-4}{x^2-x-2}\), classify each denominator zero.

12. Find k so \(f(x)=x^2+k\) for x≤2 and \(f(x)=3x\) for x>2 is continuous.

13. A function is continuous on [0,6], f(0)=-1 and f(6)=10. Justify existence of c with f(c)=4.

14. Can IVT determine the exact number of solutions to f(x)=0?

15. If f and g are continuous at c, is f+g continuous at c? Give a reason.

16. A function has a removable discontinuity at c with limit L. What single change makes it continuous?

Mastery

17. Find a so \(f(x)=\frac{x^2-a^2}{x-a}\) for x≠a and f(a)=10 is continuous at x=a.

18. A continuous function on [1,5] has f(1)=-2 and f(5)=6. A student claims there must be exactly one zero. Evaluate the claim.

19. Suppose f is continuous on [0,4] and never equals 3. If f(0)=1, what can be concluded about f(4) relative to 3?

20. For \(f(x)=\frac{x^2-5x+6}{x-2}\), define f(2) for continuity and state the resulting simplified function away from 2.

21. A piecewise function has left limit 4, right limit 4, but point value -2. Which AP continuity condition fails?

22. Verify whether \(f(x)=|x|\) is continuous at 0 using the definition of continuity.

23. A function is continuous on [2,8] with f(2)=10 and f(8)=1. List two different target values IVT guarantees and explain.

24. Construct a piecewise function with a removable discontinuity at x=1 and state the repair value.
