Algebra 1 — Unit 1: Foundations of Functions and Algebra

Essential Standard / Enduring Understanding

Students will connect tables, graphs, equations, and contexts that represent the same relationship.

Unit Source Alignment

Framework Alignment
  • Framework Topics / Standards: Students will connect tables, graphs, equations, and contexts that represent the same relationship. The supplied Framework names the five-section sequence Section 1.1: Multiple Representations of Relationships; Section 1.2: Inputs, Outputs, and Functions; Section 1.3: Function Families; Section 1.4: Expressions and Structure; Section 1.5: Equations as Models; it does not provide formal external standards codes, so none are added here.
  • Course-Specific Emphasis: Spiral retrieval, delayed summative evidence, multiple representations, mathematical reasoning, modeling, communication, and transfer across contexts.
  • Pacing Guidance: Use the Framework sequence and spiral relationships flexibly. This plan does not convert the course into a fixed Day 1 / Day 2 / Day 3 calendar.

Section Outline

Section 1.1: Multiple Representations of Relationships

Learning Target: Students will connect tables, graphs, equations, and contexts that represent the same relationship.

I Can Statements

  • I can construct a table, graph, equation, or context from another representation of the same relationship.
  • I can use features in one representation to work with a related table, graph, equation, or context.
  • I can determine whether two representations belong to the same relationship using evidence from values, rates, or patterns.

Key Vocabulary / Notation

  • input
  • output
  • ordered pair
  • table
  • graph
  • equation
  • context

Key Representations

  • Tables of input-output pairs
  • Coordinate graphs
  • Equations and rules
  • Verbal contexts
  • Connections among multiple representations

Common Misconceptions / Failure Points

  • Treating two representations as different relationships because they look different.
  • Matching representations by a single point while ignoring rate, scale, or other values.
  • Reading a graph without checking axis labels or scale.

Modeling / Application Opportunities

  • Build a graph from a context about distance, cost, or time.
  • Formulate an equation from a table of values.
  • Use a graph to predict a missing table value.
  • Check whether a context and equation communicate the same relationship.

Spiral Planning

Intro: Students will connect tables, graphs, equations, and contexts that represent the same relationship.

Review: Compare relationships using equations, graphs, tables, visual patterns, and contexts, then justify conclusions.

Mastery: Accurately perform operations with integers, fractions, and decimals while interpreting results in mathematical and contextual situations; also analyze and rewrite algebraic expressions using properties of operations and algebraic structure.

Section 1.2: Inputs, Outputs, and Functions

Learning Target: Students will interpret functions as rules that connect inputs and outputs without relying on formal domain and range language.

I Can Statements

  • I can formulate a rule that connects inputs to outputs in a table, graph, equation, or context.
  • I can apply an input-output rule to generate missing values and ordered pairs.
  • I can assess whether a rule gives one output for each input in a situation.

Key Vocabulary / Notation

  • input
  • output
  • function
  • rule
  • ordered pair
  • mapping

Key Representations

  • Input-output tables
  • Function rules
  • Ordered pairs
  • Mapping diagrams
  • Context-based input and output quantities

Common Misconceptions / Failure Points

  • Reversing which quantity is the input and which is the output.
  • Assuming every relation is a function without checking whether an input has more than one output.
  • Applying a rule inconsistently across rows or ordered pairs.

Modeling / Application Opportunities

  • Build a function rule from repeated input-output calculations.
  • Use a context to assign inputs and outputs meaning.
  • Predict outputs for new inputs using a rule.
  • Check a mapping for repeated inputs with different outputs.

Spiral Planning

Intro: Students will interpret functions as rules that connect inputs and outputs without relying on formal domain and range language.

Review: Identify patterns and represent relationships using input-output rules, tables, words, and symbols.

Mastery: Evaluate numerical and algebraic expressions correctly using substitution and order of operations.

Section 1.3: Function Families

Learning Target: Students will recognize common function families from graphs, tables, equations, and contexts.

I Can Statements

  • I can design examples of linear, quadratic, exponential, and absolute value relationships using more than one representation.
  • I can extend patterns in tables, graphs, equations, and contexts to work with common function families.
  • I can critique a proposed function family choice using evidence from rate of change, shape, or equation structure.

Key Vocabulary / Notation

  • linear
  • quadratic
  • exponential
  • absolute value
  • function family
  • key feature

Key Representations

  • Linear patterns
  • Quadratic patterns
  • Exponential growth and decay patterns
  • Absolute value patterns
  • Family features across representations

Common Misconceptions / Failure Points

  • Classifying a function from surface appearance instead of structural evidence.
  • Confusing constant difference, constant second difference, and constant ratio evidence.
  • Assuming one point or one short segment determines a function family.

Modeling / Application Opportunities

  • Create a context that fits a given family feature.
  • Use table patterns to choose a likely family.
  • Predict how a graph changes when a family pattern changes.
  • Critique family choices that rely only on appearance.

Spiral Planning

Intro: Students will recognize common function families from graphs, tables, equations, and contexts.

Review: Recognize constant rate of change in tables, graphs, visual patterns, and situations; also compare relationships using equations, graphs, tables, visual patterns, and contexts, then justify conclusions.

Mastery: Accurately perform operations with integers, fractions, and decimals while interpreting results in mathematical and contextual situations; also analyze and rewrite algebraic expressions using properties of operations and algebraic structure.

Section 1.4: Expressions and Structure

Learning Target: Students will interpret and rewrite algebraic expressions by identifying structure, meaning, and equivalent forms.

I Can Statements

  • I can build equivalent expressions by using structure, grouping, and properties of operations.
  • I can apply rewriting strategies to make the meaning of an expression easier to work with.
  • I can determine whether two expressions are equivalent by using structure, substitution, or properties.

Key Vocabulary / Notation

  • term
  • coefficient
  • factor
  • constant
  • equivalent expression
  • distributive property

Key Representations

  • Algebraic expressions
  • Equivalent forms
  • Grouped terms and factors
  • Context meanings for terms
  • Substitution checks

Common Misconceptions / Failure Points

  • Combining unlike terms as though they were like terms.
  • Distributing to only one term or losing a sign.
  • Changing an expression’s value while attempting to rewrite it equivalently.

Modeling / Application Opportunities

  • Build an expression for a cost, perimeter, or repeated quantity.
  • Rewrite an expression to reveal a useful structure.
  • Use substitution to test equivalence.
  • Connect terms and coefficients to a context.

Spiral Planning

Intro: Students will interpret and rewrite algebraic expressions by identifying structure, meaning, and equivalent forms.

Review: Identify patterns and represent relationships using input-output rules, tables, words, and symbols.

Mastery: Analyze and rewrite algebraic expressions using properties of operations and algebraic structure.

Section 1.5: Equations as Models

Learning Target: Students will write, solve, and interpret equations that model situations.

I Can Statements

  • I can construct an equation that models a situation using meaningful quantities and operations.
  • I can use solution steps to solve an equation and connect the result to the situation.
  • I can predict whether a solution is reasonable by interpreting it in the original context.

Key Vocabulary / Notation

  • variable
  • equation
  • solution
  • inverse operation
  • constraint
  • interpretation

Key Representations

  • Context-based equations
  • Solution steps
  • Variables as quantities
  • Balanced relationships
  • Interpreted solutions

Common Misconceptions / Failure Points

  • Performing an operation on only one side of an equation.
  • Reporting a numerical solution without interpreting its contextual meaning or units.
  • Accepting an algebraic result that does not satisfy the original equation or context.

Modeling / Application Opportunities

  • Formulate an equation from a real-world situation.
  • Use a solution to answer a context question.
  • Predict a reasonable value before solving.
  • Check whether a solution makes sense in context.

Spiral Planning

Intro: Students will write, solve, and interpret equations that model situations.

Review: Represent linear relationships using tables, graphs, equations, and contextual descriptions.

Mastery: Solve one-variable equations and interpret solutions within mathematical and contextual situations; also solve inequalities, represent solution sets graphically, and interpret solutions in context.

Unit Themes / Throughlines

  • Relationships can be represented by tables, graphs, equations, and contexts.
  • Functions connect inputs to outputs through rules and patterns.
  • Function families have features that appear across representations.
  • Expression structure can reveal meaning and support rewriting.
  • Equations can model situations and produce interpretable solutions.

Mastery Goals

U1-MG01

Use rational-number operations, substitution, and order of operations accurately to evaluate quantities and expressions.

Supporting learning / prerequisites

  • I can construct accurate rational number computations using integers, fractions, and decimals in mathematical and contextual situations.
  • I can apply operation rules to calculate sums, differences, products, and quotients with rational numbers.
  • I can assess whether rational number results are reasonable for the situation they represent.
  • I can formulate a clear sequence of steps for evaluating numerical and algebraic expressions.
  • I can use substitution and order of operations to calculate expression values accurately.

Key representations

  • Integer expressions
  • Fraction operations
  • Decimal operations
  • Number line models
  • Contextual quantities
  • Numerical expressions
  • Algebraic expressions

Recurring practices

  • attend to sign, operation, and equality/inequality precision
  • check results by substitution, estimation, or contextual reasonableness
  • explain how algebraic structure supports each step

What Meeting evidence should demonstrate: Independently demonstrates the goal with accurate mathematics, appropriate representation use, and an interpretation or justification that is consistent with the original task or context.

Common evidence weaknesses / misconceptions

  • Using a correct procedure without connecting the result to the representation or context.
  • Ignoring signs, scale, units, or restrictions that change the mathematical meaning.
  • Accepting a result without checking it against the original relationship.
