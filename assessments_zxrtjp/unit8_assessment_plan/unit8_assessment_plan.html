Section Outline

Section 8.1: Selecting Appropriate Models

Learning Target: Students will determine whether a situation is best modeled by a linear, quadratic, or exponential function.

I Can Statements

  • I can construct evidence from tables, graphs, and contexts to choose a linear, quadratic, or exponential model.
  • I can apply rate, second-difference, and ratio patterns to select an appropriate function family.
  • I can determine whether a chosen model is reasonable for a situation and its data pattern.

Key Vocabulary / Notation

  • linear model
  • quadratic model
  • exponential model
  • first difference
  • second difference
  • ratio

Key Representations

  • Linear, quadratic, and exponential graphs
  • Tables showing first differences, second differences, and ratios
  • Equations in familiar function forms
  • Context descriptions with quantities and constraints
  • Verbal claims about growth, change, and turning behavior

Common Misconceptions / Failure Points

  • Choosing a family from a keyword in the context instead of data/feature evidence.
  • Using first differences, second differences, or ratios inconsistently.
  • Assuming a good local fit guarantees a good model over all inputs.

Modeling / Application Opportunities

  • Sort situations by evidence rather than by surface words.
  • Choose a model for a data table and state the feature that supports the choice.
  • Revise a model choice when a new data point changes the pattern.
  • Connect real-world behavior to graph shape and equation structure.

Spiral Planning

Intro: Students will determine whether a situation is best modeled by a linear, quadratic, or exponential function.

Review: Compare linear, quadratic, and exponential functions using multiple representations; also create and analyze exponential models using real-world data.

Mastery: Compare factoring, completing the square, and the quadratic formula and select efficient solution methods; also use quadratic functions to model real-world situations and interpret maximums, minimums, and intercepts.

Section 8.2: Transformations Across Function Families

Learning Target: Students will analyze transformations across multiple function families.

I Can Statements

  • I can build transformed function rules from parent functions across linear, quadratic, exponential, and absolute value families.
  • I can use key points and key features to graph transformations across multiple function families.
  • I can formulate a transformation description that connects parameter changes to key point shifts across function families.

Key Vocabulary / Notation

  • parent function
  • translation
  • reflection
  • stretch
  • compression
  • key point

Key Representations

  • Parent function graphs
  • Transformed equations such as $f(x)+k$, $f(x-h)$, and $af(x)$
  • Key points before and after transformations
  • Feature tables for intercepts, vertex, asymptote, and direction
  • Context descriptions involving shifted or scaled models

Common Misconceptions / Failure Points

  • Applying a transformation rule differently to different function families.
  • Reversing horizontal shift direction.
  • Confusing a transformation of outputs with a transformation of inputs.

Modeling / Application Opportunities

  • Move key points to create a transformed model for a situation.
  • Predict how changing a parameter changes a graph and its meaning.
  • Use transformations to adapt a familiar model to a new context.
  • Check whether a transformed equation preserves important constraints.

Spiral Planning

Intro: Students will analyze transformations across multiple function families.

Review: Graph exponential functions and analyze key features.

Mastery: Solve quadratic equations by completing the square and connect the process to vertex form; also use quadratic functions to model real-world situations and interpret maximums, minimums, and intercepts.

Section 8.3: Absolute Value Functions and Piecewise Thinking

Learning Target: Students will analyze and model situations involving absolute value functions.

I Can Statements

  • I can design an absolute value or piecewise representation for situations with distance, change in direction, or two-part behavior.
  • I can apply key features of absolute value graphs to interpret vertex, intercepts, and rate of change.
  • I can predict outputs and intervals from absolute value and piecewise rules in context.

Key Vocabulary / Notation

  • absolute value
  • vertex
  • piecewise function
  • interval
  • domain
  • rate of change

Key Representations

  • Absolute value graphs with a vertex
  • Equations using $|x-h|$ structure
  • Piecewise rules and interval restrictions
  • Tables showing symmetry or two rates
  • Contexts involving distance from a target or changing direction

Common Misconceptions / Failure Points

  • Treating absolute value as simply “make the output positive.”
  • Ignoring interval conditions in a piecewise rule.
  • Confusing the vertex with an intercept or failing to interpret the two rates on either side.

Modeling / Application Opportunities

  • Model distance from a target value using absolute value.
  • Create a piecewise rule for a situation with different rates over intervals.
  • Connect a vertex to a minimum distance or turning point in context.
  • Use domain restrictions to make a model fit the situation.

Spiral Planning

Intro: Students will analyze and model situations involving absolute value functions.

Review: Graph exponential functions and analyze key features; also compare linear, quadratic, and exponential functions using multiple representations.

Mastery: Solve quadratic equations using factored form and interpret solutions; also compare factoring, completing the square, and the quadratic formula and select efficient solution methods.

Section 8.4: Modeling Investigation

Learning Target: Students will create and analyze mathematical models using real-world data.

I Can Statements

  • I can formulate a mathematical model from real-world data and state the assumptions used.
  • I can extend a model to make predictions within a reasonable domain.
  • I can critique how well a model fits data, constraints, and the situation being studied.

Key Vocabulary / Notation

  • model
  • assumption
  • domain
  • prediction
  • fit
  • constraint
  • residual

Key Representations

  • Real-world data tables
  • Scatterplots or plotted coordinate pairs
  • Candidate linear, quadratic, exponential, or absolute value models
  • Residual-style observations about overprediction and underprediction
  • Written interpretation of model parameters and limits

Common Misconceptions / Failure Points

  • Choosing a model before examining patterns and constraints.
  • Reporting a prediction without identifying assumptions or a reasonable domain.
  • Treating deviations from the model as proof the model is useless rather than evidence about fit.

Modeling / Application Opportunities

  • Choose a model for a small data set and defend the choice with evidence.
  • Use a model to make and check a prediction.
  • Revise a model when the data or domain makes the first model weak.
  • Interpret parameters and outputs in the original context.

Spiral Planning

Intro: Students will create and analyze mathematical models using real-world data.

Review: Create and analyze exponential models using real-world data.

Mastery: Solve quadratic equations using the quadratic formula and interpret solutions; also use quadratic functions to model real-world situations and interpret maximums, minimums, and intercepts.

Section 8.5: Function Synthesis and Capstone Analysis

Learning Target: Students will synthesize understanding of function families and representations to solve complex problems.

I Can Statements

  • I can construct a solution pathway that connects equations, graphs, tables, and contexts across function families.
  • I can use multiple representations to solve complex function problems and interpret results.
  • I can assess competing solution strategies and choose the representation that best supports the conclusion.

Key Vocabulary / Notation

  • function family
  • representation
  • parameter
  • key feature
  • model
  • constraint

Key Representations

  • Multiple function-family graphs
  • Tables, equations, and contexts used together
  • Function-feature summaries
  • Student-generated model comparisons
  • Written reasoning about model choice and solution meaning

Common Misconceptions / Failure Points

  • Using one representation for every task even when another reveals the needed feature more clearly.
  • Combining features from different function families inconsistently.
  • Defending a conclusion with calculations but no connection to the context or model limits.

Modeling / Application Opportunities

  • Select efficient representations for multi-step function tasks.
  • Synthesize evidence from several function families to solve a problem.
  • Revise a model or solution when a representation reveals a conflict.
  • Communicate why a chosen model or strategy fits the problem conditions.

Spiral Planning

Intro: Students will synthesize understanding of function families and representations to solve complex problems.

Review: Compare linear, quadratic, and exponential functions using multiple representations; also create and analyze exponential models using real-world data.

Mastery: Solve quadratic equations using factored form and interpret solutions; Solve quadratic equations by completing the square and connect the process to vertex form; Solve quadratic equations using the quadratic formula and interpret solutions; Compare factoring, completing the square, and the quadratic formula and select efficient solution methods; and use quadratic functions to model real-world situations and interpret maximums, minimums, and intercepts.

Unit Themes / Throughlines

  • Choosing function families based on evidence from patterns, features, and context
  • Connecting equations, graphs, tables, and verbal descriptions as equivalent or complementary representations
  • Interpreting parameters, intercepts, vertices, asymptotic behavior, and intervals in context
  • Using transformations and restrictions to adapt parent functions to real situations
  • Critiquing model fit, domain, reasonableness, and representation choice

Mastery Goals

U8-MG01

Solve quadratic equations by factoring and interpret all valid solutions.

Supporting learning / prerequisites

  • I can construct factored quadratic equations from given zeros, intercepts, or contextual constraints.
  • I can apply the zero product property to solve quadratic equations in factored form.
  • I can determine whether solutions make sense in relation to a graph or context.

Key representations

  • Factored quadratic equations
  • Zeros and $x$-intercepts
  • Tables of values
  • Graphs of parabolas
  • Contextual solution statements

Recurring practices

  • verify quadratic solutions in the original equation or context
  • choose a method based on equation structure
  • connect algebraic solutions to graph features and model meaning

What Meeting evidence should demonstrate: Independently demonstrates the goal with accurate mathematics, appropriate representation use, and an interpretation or justification that is consistent with the original task or context.

Common evidence weaknesses / misconceptions

  • Using the zero-product property before the equation is set equal to zero.
  • Dropping one factor and reporting only one solution.
  • Accepting extraneous arithmetic or factoring errors without checking.
U8-MG02

Solve quadratic equations by completing the square and connect the process to vertex form.

Supporting learning / prerequisites

  • I can build perfect-square trinomials by adding the needed constant term.
  • I can use completing the square to solve quadratic equations and write equivalent vertex-form expressions.
  • I can predict how completing the square reveals the vertex and symmetry of a quadratic function.

Key representations

  • Standard form equations
  • Perfect-square trinomials
  • Vertex form expressions
  • Algebra tiles or area models
  • Parabola vertices and axes of symmetry

Recurring practices

  • verify quadratic solutions in the original equation or context
  • choose a method based on equation structure
  • connect algebraic solutions to graph features and model meaning

What Meeting evidence should demonstrate: Independently demonstrates the goal with accurate mathematics, appropriate representation use, and an interpretation or justification that is consistent with the original task or context.

Common evidence weaknesses / misconceptions

  • Adding a value to one side but not the other.
  • Using half the linear coefficient incorrectly when forming the square.
  • Failing to connect the completed-square form to the vertex or solutions.
U8-MG03

Use the quadratic formula accurately and interpret the number and meaning of solutions.

Supporting learning / prerequisites

  • I can design a coefficient map that organizes $a$, $b$, and $c$ before using the quadratic formula.
  • I can apply the quadratic formula to solve equations with rational, irrational, or no real solutions.
  • I can assess how the discriminant predicts the number and type of real solutions.

Key representations

  • Standard form equations
  • Quadratic formula
  • Discriminant values
  • Exact and approximate solutions
  • Graphs with two, one, or no $x$-intercepts

Recurring practices

  • verify quadratic solutions in the original equation or context
  • choose a method based on equation structure
  • connect algebraic solutions to graph features and model meaning

What Meeting evidence should demonstrate: Independently demonstrates the goal with accurate mathematics, appropriate representation use, and an interpretation or justification that is consistent with the original task or context.

Common evidence weaknesses / misconceptions

  • Substituting signs for $a$, $b$, and $c$ incorrectly.
  • Forgetting that $-b$ changes the sign of $b$.
  • Treating the discriminant as the solution instead of evidence about solution type.
U8-MG04

Select and justify efficient quadratic solution methods and use quadratic models to interpret extrema, intercepts, and contextual constraints.

Supporting learning / prerequisites

  • I can formulate a solution-method plan based on the structure of a quadratic equation.
  • I can use factoring, completing the square, or the quadratic formula when the equation structure supports the method.
  • I can critique a selected solution method for efficiency, accuracy, and fit to the equation.
  • I can construct quadratic models from real-world constraints, data, or key features.
  • I can extend quadratic models to predict maximums, minimums, intercepts, and meaningful solution values.

Key representations

  • Standard form equations
  • Factored form equations
  • Vertex form equations
  • Method-selection flowcharts
  • Written solution-method comparisons
  • Contextual quadratic models
  • Graphs with vertices and intercepts

Recurring practices

  • verify quadratic solutions in the original equation or context
  • choose a method based on equation structure
  • connect algebraic solutions to graph features and model meaning

What Meeting evidence should demonstrate: Independently demonstrates the goal with accurate mathematics, appropriate representation use, and an interpretation or justification that is consistent with the original task or context.

Common evidence weaknesses / misconceptions

  • Choosing a method by habit instead of using equation structure.
  • Assuming factoring is always fastest or always possible.
  • Giving a correct method choice without explaining the structural reason.
  • Interpreting the vertex without checking whether it is a maximum or minimum.
