Algebra 1 — Unit 6: Solving and Modeling with Quadratics

Essential Standard / Enduring Understanding

Students will solve quadratic equations using factored form and interpret solutions.

Section Outline

Section 6.1: Solving Quadratics by Factoring

Learning Target: Students will solve quadratic equations using factored form and interpret solutions.

I Can Statements

  • I can construct factored quadratic equations from given zeros, intercepts, or contextual constraints.
  • I can apply the zero product property to solve quadratic equations in factored form.
  • I can determine whether solutions make sense in relation to a graph or context.

Key Vocabulary / Notation

  • quadratic equation
  • factored form
  • zero-product property
  • root
  • solution

Key Representations

  • Factored quadratic equations
  • Zeros and $x$-intercepts
  • Tables of values
  • Graphs of parabolas
  • Contextual solution statements

Common Misconceptions / Failure Points

  • Using the zero-product property before the equation is set equal to zero.
  • Dropping one factor and reporting only one solution.
  • Accepting extraneous arithmetic or factoring errors without checking.

Modeling / Application Opportunities

  • Model break-even points using factored quadratic equations
  • Connect ground-contact times to zeros in projectile contexts
  • Represent rectangular area relationships with products of linear factors
  • Interpret when negative or repeated solutions are meaningful

Spiral Planning

Intro: Students will solve quadratic equations using factored form and interpret solutions.

Review: Factor quadratic trinomials using patterns, products, sums, and structure; also connect factors, zeros, intercepts, and graphs of quadratic functions.

Mastery: Add, subtract, and multiply polynomial expressions; also connect polynomial expressions to quadratic graphs and key features.

Section 6.2: Completing the Square

Learning Target: Students will solve quadratic equations by completing the square and connect the process to vertex form.

I Can Statements

  • I can build perfect-square trinomials by adding the needed constant term.
  • I can use completing the square to solve quadratic equations and write equivalent vertex-form expressions.
  • I can predict how completing the square reveals the vertex and symmetry of a quadratic function.

Key Vocabulary / Notation

  • complete the square
  • perfect-square trinomial
  • vertex form
  • square root

Key Representations

  • Standard form equations
  • Perfect-square trinomials
  • Vertex form expressions
  • Algebra tiles or area models
  • Parabola vertices and axes of symmetry

Common Misconceptions / Failure Points

  • Adding a value to one side but not the other.
  • Using half the linear coefficient incorrectly when forming the square.
  • Failing to connect the completed-square form to the vertex or solutions.

Modeling / Application Opportunities

  • Model height or profit situations where the maximum or minimum is most useful
  • Connect area diagrams to completing-square steps
  • Rewrite quadratic models to reveal optimal input values
  • Interpret constants introduced during equivalent transformations

Spiral Planning

Intro: Students will solve quadratic equations by completing the square and connect the process to vertex form.

Review: Compare standard, vertex, and factored forms of quadratic functions and determine which form best reveals key features.

Mastery: Graph and write translated functions using key points and key features; also connect polynomial expressions to quadratic graphs and key features.

Section 6.3: Quadratic Formula

Learning Target: Students will solve quadratic equations using the quadratic formula and interpret solutions.

I Can Statements

  • I can design a coefficient map that organizes $a$, $b$, and $c$ before using the quadratic formula.
  • I can apply the quadratic formula to solve equations with rational, irrational, or no real solutions.
  • I can assess how the discriminant predicts the number and type of real solutions.

Key Vocabulary / Notation

  • quadratic formula
  • discriminant
  • $a$
  • $b$
  • $c$
  • real solution

Key Representations

  • Standard form equations
  • Quadratic formula
  • Discriminant values
  • Exact and approximate solutions
  • Graphs with two, one, or no $x$-intercepts

Common Misconceptions / Failure Points

  • Substituting signs for $a$, $b$, and $c$ incorrectly.
  • Forgetting that $-b$ changes the sign of $b$.
  • Treating the discriminant as the solution instead of evidence about solution type.

Modeling / Application Opportunities

  • Model solution type using the discriminant before calculating roots
  • Connect irrational solutions to graphing-window estimates
  • Interpret no-real-solution cases in physical contexts
  • Use formula outputs to answer context-specific questions

Spiral Planning

Intro: Students will solve quadratic equations using the quadratic formula and interpret solutions.

Review: Identify common factors and use structure to rewrite polynomial expressions; also factor quadratic trinomials using patterns, products, sums, and structure.

Mastery: Add, subtract, and multiply polynomial expressions.

Section 6.4: Choosing and Defending Solution Methods

Learning Target: Students will compare factoring, completing the square, and the quadratic formula and select efficient solution methods.

I Can Statements

  • I can formulate a solution-method plan based on the structure of a quadratic equation.
  • I can use factoring, completing the square, or the quadratic formula when the equation structure supports the method.
  • I can critique a selected solution method for efficiency, accuracy, and fit to the equation.

Key Vocabulary / Notation

  • factoring
  • completing the square
  • quadratic formula
  • efficiency
  • structure

Key Representations

  • Standard form equations
  • Factored form equations
  • Vertex form equations
  • Method-selection flowcharts
  • Written solution-method comparisons

Common Misconceptions / Failure Points

  • Choosing a method by habit instead of using equation structure.
  • Assuming factoring is always fastest or always possible.
  • Giving a correct method choice without explaining the structural reason.

Modeling / Application Opportunities

  • Model decision-making with method-selection criteria
  • Revise inefficient solution plans for the same equation
  • Connect equation structure to the most efficient solving strategy
  • Interpret whether exact or approximate solutions are more useful

Spiral Planning

Intro: Students will compare factoring, completing the square, and the quadratic formula and select efficient solution methods.

Review: Factor quadratic trinomials using patterns, products, sums, and structure; also compare standard, vertex, and factored forms of quadratic functions and determine which form best reveals key features.

Mastery: Identify common function families from graphs, equations, tables, and contexts; also connect polynomial expressions to quadratic graphs and key features.

Section 6.5: Quadratic Modeling and Optimization

Learning Target: Students will use quadratic functions to model real-world situations and interpret maximums, minimums, and intercepts.

I Can Statements

  • I can construct quadratic models from real-world constraints, data, or key features.
  • I can extend quadratic models to predict maximums, minimums, intercepts, and meaningful solution values.
  • I can assess whether a quadratic model and its solutions are reasonable for the situation.

Key Vocabulary / Notation

  • quadratic model
  • vertex
  • maximum
  • minimum
  • intercept
  • domain

Key Representations

  • Contextual quadratic models
  • Graphs with vertices and intercepts
  • Tables of input-output values
  • Vertex, standard, and factored forms
  • Domain restrictions and solution interpretations

Common Misconceptions / Failure Points

  • Interpreting the vertex without checking whether it is a maximum or minimum.
  • Using algebraically valid solutions that fall outside the contextual domain.
  • Confusing intercept meaning with vertex meaning.

Modeling / Application Opportunities

  • Model projectile height over time
  • Optimize area or revenue using quadratic functions
  • Interpret maximums and minimums in context
  • Restrict domains to meaningful values in real-world situations

Spiral Planning

Intro: Students will use quadratic functions to model real-world situations and interpret maximums, minimums, and intercepts.

Review: Connect factors, zeros, intercepts, and graphs of quadratic functions; also compare standard, vertex, and factored forms of quadratic functions and determine which form best reveals key features.

Mastery: Graph and write translated functions using key points and key features; Analyze and graph transformations involving stretches, compressions, and reflections; and connect polynomial expressions to quadratic graphs and key features.

Unit Themes / Throughlines

  • Choosing a quadratic form based on the feature needed
  • Connecting symbolic solutions to graph intercepts and contextual meaning
  • Using structure to select efficient solving methods
  • Interpreting maximums, minimums, zeros, and restrictions in real-world models
  • Checking reasonableness of solutions against graphs, tables, and contexts

Mastery Goals

U6-MG01

Identify function families from equations, graphs, tables, and contexts using structural evidence.

Supporting learning / prerequisites

  • I can construct evidence for a function family using patterns in graphs, equations, tables, and contexts.
  • I can apply family features to sort representations into linear, quadratic, exponential, absolute value, and other familiar forms.
  • I can determine which representation gives the strongest evidence for a function family when features seem similar.

Key representations

  • Graphs of parent and familiar function families
  • Tables showing constant differences, second differences, or ratios
  • Equations in recognizable family forms
  • Contexts involving change patterns
  • Feature language such as intercept, vertex, rate, and symmetry

Recurring practices

  • track key points and structural features across transformations
  • connect symbolic changes to graphical effects
  • use polynomial structure and graph features together

What Meeting evidence should demonstrate: Independently demonstrates the goal with accurate mathematics, appropriate representation use, and an interpretation or justification that is consistent with the original task or context.

Common evidence weaknesses / misconceptions

  • Classifying from one feature while ignoring contradictory evidence.
  • Confusing additive, second-difference, and multiplicative patterns.
  • Assuming every curved graph is quadratic.
U6-MG02

Represent and analyze translations, reflections, stretches, and compressions using key points and features.

Supporting learning / prerequisites

  • I can build translated graphs by moving key points and key features from a parent function.
  • I can use horizontal and vertical shifts to write equations for translated functions.
  • I can predict how changing values in an equation moves a graph left, right, up, or down.
  • I can design transformed graphs using stretches, compressions, reflections, and translations of parent functions.
  • I can apply transformation rules to key points and features across function families.

Key representations

  • Parent function graphs
  • Translated graphs on coordinate grids
  • Equations in transformation form
  • Key points, vertices, intercepts, and asymptotes where appropriate
  • Tables before and after translation
  • Transformation equations using parameters
  • Graphs showing vertical stretches and compressions

Recurring practices

  • track key points and structural features across transformations
  • connect symbolic changes to graphical effects
  • use polynomial structure and graph features together

What Meeting evidence should demonstrate: Independently demonstrates the goal with accurate mathematics, appropriate representation use, and an interpretation or justification that is consistent with the original task or context.

Common evidence weaknesses / misconceptions

  • Reversing the direction of a horizontal shift in $f(x-h)$.
  • Moving every point inconsistently instead of applying one translation.
  • Changing shape or scale when only a translation is intended.
  • Confusing vertical and horizontal scaling effects.
U6-MG03

Add, subtract, and multiply polynomial expressions accurately using algebraic structure.

Supporting learning / prerequisites

  • I can formulate polynomial sums, differences, and products from area, perimeter, and expression contexts.
  • I can use structure and like terms to add, subtract, and multiply polynomial expressions.
  • I can extend polynomial operations to equivalent expressions written in different forms.

Key representations

  • Polynomial expressions in standard and factored forms
  • Area models and algebra tiles
  • Tables of expression values
  • Equivalent expressions after combining or multiplying terms
  • Contextual diagrams involving length, width, area, and total change

Recurring practices

  • track key points and structural features across transformations
  • connect symbolic changes to graphical effects
  • use polynomial structure and graph features together

What Meeting evidence should demonstrate: Independently demonstrates the goal with accurate mathematics, appropriate representation use, and an interpretation or justification that is consistent with the original task or context.

Common evidence weaknesses / misconceptions

  • Combining terms with different variable parts or exponents.
  • Failing to distribute every term when multiplying polynomials.
  • Adding exponents during addition instead of only when multiplying like bases.
U6-MG04

Connect polynomial structure to quadratic graphs and interpret key quadratic features.

Supporting learning / prerequisites

  • I can construct connections between polynomial structure, quadratic graphs, and key features.
  • I can predict graph features from equivalent quadratic expressions.
  • I can critique whether a polynomial expression supports a claimed vertex, intercept, axis of symmetry, or direction of opening.

Key representations

  • Quadratic expressions in equivalent forms
  • Parabolas with vertex, intercepts, and axis of symmetry
  • Tables showing quadratic patterns
  • Factored or expanded expressions connected to graph features
  • Contexts modeled by quadratic relationships

Recurring practices

  • track key points and structural features across transformations
  • connect symbolic changes to graphical effects
  • use polynomial structure and graph features together

What Meeting evidence should demonstrate: Independently demonstrates the goal with accurate mathematics, appropriate representation use, and an interpretation or justification that is consistent with the original task or context.

Common evidence weaknesses / misconceptions

  • Assuming every polynomial produces a quadratic graph.
  • Confusing coefficients with zeros or intercepts.
  • Reading the vertex or axis of symmetry inaccurately from a representation.
