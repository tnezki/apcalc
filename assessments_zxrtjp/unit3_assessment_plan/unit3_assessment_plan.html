Algebra 1 — Unit 3: Systems and Constraints

Essential Standard / Enduring Understanding

Students will solve systems graphically and by elimination while interpreting the meaning of different solution types.

Unit Source Alignment

Section Outline

Section 3.1: Graphing and Elimination

Learning Target: Students will solve systems graphically and by elimination while interpreting the meaning of different solution types.

I Can Statements

  • I can construct graphical representations of systems and connect intersection points to solutions.
  • I can use elimination to solve systems and interpret the solution type.
  • I can determine whether a system has one solution, no solution, or infinitely many solutions from algebraic and graphical evidence.

Key Vocabulary / Notation

  • system of equations
  • intersection
  • solution
  • elimination
  • no solution
  • infinitely many solutions

Key Representations

  • Graphs of two linear equations
  • Tables of paired values
  • Standard form equations
  • Intersection points
  • Solution-type statements

Common Misconceptions / Failure Points

  • Treating elimination as a procedure without preserving equivalent equations.
  • Misinterpreting parallel or identical lines as having one solution.
  • Failing to connect an algebraic solution to the graph intersection.

Modeling / Application Opportunities

  • Represent two competing plans as a system of equations
  • Interpret an intersection as a break-even point
  • Connect elimination steps to equivalent constraints
  • Use solution types to interpret whether a situation is possible, impossible, or always true

Spiral Planning

Intro: Students will solve systems graphically and by elimination while interpreting the meaning of different solution types.

Review: Graph linear functions and interpret key features; also write linear equations from graphs, tables, and situations.

Mastery: Connect tables, graphs, equations, and contexts that represent the same relationship; also write, solve, and interpret equations that model situations.

Section 3.2: Solving Systems by Substitution

Learning Target: Students will solve systems using substitution and choose efficient forms for solving.

I Can Statements

  • I can formulate a substitution plan when one equation is already written in an efficient form.
  • I can apply substitution to solve systems and interpret the ordered-pair solution.
  • I can assess which algebraic method is more efficient for a given system.

Key Vocabulary / Notation

  • substitution
  • system
  • equivalent equation
  • solution
  • ordered pair

Key Representations

  • Slope-intercept form equations
  • Equations solved for one variable
  • Substitution work
  • Ordered-pair solutions
  • Contextual solution statements

Common Misconceptions / Failure Points

  • Substituting into the same equation instead of the other equation.
  • Losing parentheses or signs when substituting an expression.
  • Stopping after finding one variable and not recovering the ordered-pair solution.

Modeling / Application Opportunities

  • Represent one quantity in terms of another before solving
  • Use substitution to connect two related constraints
  • Interpret a solution in a two-variable situation
  • Select an efficient solving pathway based on equation structure

Spiral Planning

Intro: Students will solve systems using substitution and choose efficient forms for solving.

Review: Write linear equations from graphs, tables, and situations.

Mastery: Interpret functions as rules that connect inputs and outputs without relying on formal domain and range language; also interpret and rewrite algebraic expressions by identifying structure, meaning, and equivalent forms.

Section 3.3: Writing and Solving Systems from Situations

Learning Target: Students will create and solve systems that model real-world situations.

I Can Statements

  • I can build a system of equations that represents two constraints in a situation.
  • I can predict the meaning of a solution before solving from the context and variables.
  • I can design a solution pathway that connects equations, calculations, and a contextual conclusion.

Key Vocabulary / Notation

  • system
  • constraint
  • variable
  • equation
  • intersection
  • solution

Key Representations

  • Verbal situations
  • Variable definitions
  • Systems of equations
  • Graphs or tables for checking
  • Contextual conclusions

Common Misconceptions / Failure Points

  • Using the same variable meaning inconsistently across equations.
  • Writing two equations that do not represent the same contextual quantities.
  • Accepting an intersection that violates a real-world restriction.

Modeling / Application Opportunities

  • Create a system from ticket, mixture, cost, or comparison situations
  • Choose variables that make the constraints clear
  • Interpret both coordinates of the solution in context
  • Check whether a solution is reasonable for the situation

Spiral Planning

Intro: Students will create and solve systems that model real-world situations.

Review: Use linear models to represent and interpret real-world data.

Mastery: Connect tables, graphs, equations, and contexts that represent the same relationship; also write, solve, and interpret equations that model situations.

Section 3.4: Graphing Linear Inequalities

Learning Target: Students will graph and interpret linear inequalities.

I Can Statements

  • I can construct a boundary line and shaded region for a linear inequality.
  • I can use test points to interpret which region satisfies an inequality.
  • I can critique a graph of a linear inequality using the boundary, shading, and solution region.

Key Vocabulary / Notation

  • inequality
  • boundary line
  • solid line
  • dashed line
  • half-plane
  • solution region

Key Representations

  • Linear inequalities
  • Solid and dashed boundary lines
  • Shaded half-planes
  • Test points
  • Solution-region statements

Common Misconceptions / Failure Points

  • Using a solid boundary when the boundary is excluded, or dashed when included.
  • Shading the wrong half-plane.
  • Treating a boundary line as the entire solution set.

Modeling / Application Opportunities

  • Represent limits such as budgets, minimums, and maximums
  • Use a test point to check a feasible region
  • Interpret boundary inclusion in context
  • Connect inequality symbols to shaded solution regions

Spiral Planning

Intro: Students will graph and interpret linear inequalities.

Review: Graph linear functions and interpret key features.

Mastery: Interpret and rewrite algebraic expressions by identifying structure, meaning, and equivalent forms; also write, solve, and interpret equations that model situations.

Section 3.5: Linear Systems of Inequalities

Learning Target: Students will analyze and interpret systems of linear inequalities.

I Can Statements

  • I can formulate a system of inequalities that represents multiple constraints.
  • I can extend graphing strategies to represent overlapping solution regions.
  • I can apply feasible-region reasoning to interpret possible solutions in context.

Key Vocabulary / Notation

  • system of inequalities
  • feasible region
  • intersection
  • constraint
  • boundary

Key Representations

  • Systems of inequalities
  • Multiple boundary lines
  • Overlapping shaded regions
  • Feasible points
  • Constraint-based contexts

Common Misconceptions / Failure Points

  • Shading each inequality correctly but not identifying the overlap as the system solution.
  • Ignoring contextual constraints such as nonnegative quantities.
  • Assuming every pair of inequalities has a feasible region.

Modeling / Application Opportunities

  • Represent real-world restrictions with more than one inequality
  • Interpret feasible and non-feasible points in context
  • Use overlapping regions to model choices under constraints
  • Connect graphical solutions to decision-making situations

Spiral Planning

Intro: Students will analyze and interpret systems of linear inequalities.

Review: Analyze and compare linear relationships using multiple representations.

Mastery: Connect tables, graphs, equations, and contexts that represent the same relationship; Recognize common function families from graphs, tables, equations, and contexts; and write, solve, and interpret equations that model situations.

Unit Themes / Throughlines

  • Systems model two or more conditions that must be true at the same time
  • Solution points and solution regions represent meaningful choices or outcomes
  • Different algebraic methods can solve the same relationship efficiently depending on structure
  • Inequalities model constraints, limits, and feasible options
  • Graphs, equations, and contexts work together to support interpretation and reasonableness checks

Mastery Goals

U3-MG01

Connect tables, graphs, equations, and contexts that represent the same relationship.

Supporting learning / prerequisites

  • I can construct a table, graph, equation, or context from another representation of the same relationship.
  • I can use features in one representation to work with a related table, graph, equation, or context.
  • I can determine whether two representations belong to the same relationship using evidence from values, rates, or patterns.

Key representations

  • Tables of input-output pairs
  • Coordinate graphs
  • Equations and rules
  • Verbal contexts
  • Connections among multiple representations

Recurring practices

  • move among equations, graphs, tables, and contexts
  • interpret variables and outputs in context
  • justify function-family or equivalence claims with representation evidence

What Meeting evidence should demonstrate: Independently demonstrates the goal with accurate mathematics, appropriate representation use, and an interpretation or justification that is consistent with the original task or context.

Common evidence weaknesses / misconceptions

  • Treating two representations as different relationships because they look different.
  • Matching representations by a single point while ignoring rate, scale, or other values.
  • Reading a graph without checking axis labels or scale.

Interpret functions as input-output rules and distinguish common function families using representation evidence.

Supporting learning / prerequisites

  • I can apply an input-output rule to generate missing values and ordered pairs.
  • I can assess whether a rule gives one output for each input in a situation.
  • I can design examples of linear, quadratic, exponential, and absolute value relationships using more than one representation.
  • I can extend patterns in tables, graphs, equations, and contexts to work with common function families.

Key representations

  • Input-output tables
  • Function rules
  • Ordered pairs
  • Mapping diagrams
  • Context-based input and output quantities
  • Linear patterns
  • Quadratic patterns

Recurring practices

  • move among equations, graphs, tables, and contexts
  • interpret variables and outputs in context
  • justify function-family or equivalence claims with representation evidence

What Meeting evidence should demonstrate: Independently demonstrates the goal with accurate mathematics, appropriate representation use, and an interpretation or justification that is consistent with the original task or context.

Common evidence weaknesses / misconceptions

  • Reversing which quantity is the input and which is the output.
  • Assuming every relation is a function without checking whether an input has more than one output.
  • Applying a rule inconsistently across rows or ordered pairs.
  • Classifying a function from surface appearance instead of structural evidence.

  • I can determine whether two expressions are equivalent by using structure, substitution, or properties.

Key representations

  • Algebraic expressions
  • Equivalent forms
  • Grouped terms and factors
  • Context meanings for terms
  • Substitution checks

Recurring practices

  • move among equations, graphs, tables, and contexts
  • interpret variables and outputs in context
  • justify function-family or equivalence claims with representation evidence

What Meeting evidence should demonstrate: Independently demonstrates the goal with accurate mathematics, appropriate representation use, and an interpretation or justification that is consistent with the original task or context.

Common evidence weaknesses / misconceptions

  • Combining unlike terms as though they were like terms.

  • Changing an expression’s value while attempting to rewrite it equivalently.

Key representations

  • Context-based equations
  • Solution steps
  • Variables as quantities
  • Balanced relationships
  • Interpreted solutions

Recurring practices

  • move among equations, graphs, tables, and contexts
  • interpret variables and outputs in context
  • justify function-family or equivalence claims with representation evidence

What Meeting evidence should demonstrate: Independently demonstrates the goal with accurate mathematics, appropriate representation use, and an interpretation or justification that is consistent with the original task or context.

Common evidence weaknesses / misconceptions

  • Accepting an algebraic result that does not satisfy the original equation or context.
